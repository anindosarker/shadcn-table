# CLAUDE.md

This project is a table library built with tanstack table and shadcn/ui.

## Rules

- You can commit and push to git.
- Code and gates: `docs/code-of-conduct/coding-standards.md`. Cite by section in review.
- Plans: `docs/code-of-conduct/planning-guidelines.md`. Discuss scope in chat before writing; decisions go to `decisions.md`, never questions into plan files.
- Release and branch flow: `docs/code-of-conduct/release.md`. Merge a part on green local gates; release once per round, in the background.
- Sub-agents: every agent prompt points at `.ai/agent-rules.md` instead of repeating the rules.
