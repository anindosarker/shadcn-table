# 06.1: library fixes after the owner's review

## 1. Architecture

### 1.1 Overview

The owner's review of 0.8 on `claude/review` (2026-11-04) found regressions from 0.7.4 and defects in the shipped chrome: a custom top toolbar loses every column filter, the popover filter mode opens nothing, the row actions cell clips to one control, a detail panel does not render, display cells lost their centring, body cells misalign when row numbers turn on, group headers drift from their leaves, the sort editor ignores `maxMultiSortColCount`, the columns menu shows no icon, two locale strings (D41) (D47) (D48) (F7) (F11) (F12) (F16) (F17) (F18) (F19) (F22) (F24). This sub-spec fixes them at the root in the three bases, each with a play test that reproduces it first (P6). Two stories in sprint S6, one builder each, draft PR at the first push (P1), one fable review each (`Review: fable`): "Toolbar and filters (06.1)" owns the toolbar, menus, layout mount, locales and index; "Cells and layout (06.1)" owns the head and body cells, the width rule, the display column defs and the detail panel.

### 1.2 Goals

- With `renderTopToolbar` set and the default `columnFilterDisplayMode: 'chips'`, the column menu's Filter item opens the header-anchored editor and filters the rows; the chips row is a public component a custom toolbar can render (F17)
- "Add sort" disappears once the rule count reaches `maxMultiSortColCount` (D47) (F7)
- The columns menu renders the column icon before the label (D48)
- `localization.rowNumbers` reads "Row numbers" in English and "Zeilennummern" in German (D41) (F11)
- Display cells (select, expand, pin, drag, row numbers, actions) centre their content in header and body with the same x position; row numbers are `tabular-nums text-muted-foreground` (F12)
- With row numbers turned on through the view settings, every body cell's edges equal its header cell's edges (F16)
- A group header's edges equal the union of its leaves' edges, including when a leaf is pinned or does not grow; placeholder header cells over display columns follow the display styling (F18)
- In popover mode the funnel opens the filter popover, in every base, with row selection and sized columns present; the header label keeps its width beside funnel and chevron (F19)
- The actions cell shows every control `renderRowActions` returns, with the "Actions" header label when `renderRowActions` is set (D52) (F22)
- An expanded row renders its detail panel with its content visible in the grid layout, with and without row virtualization (F24)
- Acceptance: programmatic, the plays of 1.6.9 pass in `test:base`, `test:radix` and `test:aria`, each play written to fail on the shipped code first (its failing run noted in the tracker) and to pass after the fix
