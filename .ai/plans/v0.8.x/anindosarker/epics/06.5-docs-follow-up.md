## 1. Architecture

### 1.1 Overview

The owner's review of the 0.8 docs site on `claude/review` (2026-11-05) and the D58 sanity pass left five docs-app findings: three sidebar routes with no page behind them (F42), custom toolbars that never show the sort chip (F51), example pages written this cycle at twice the Material React Table original's length and a persistent-view body that never says localStorage (F52), a browser `window.confirm` over the styled editing examples (F53), and iconed headers in 56 to 100 px columns that truncate to one letter (F54). This sub-spec fixes them in `apps/shadcn-table-docs/` for the three bases. One story "Docs follow-up (06.5)", sprint S10, one builder, draft PR at the first push (P1), checks only (no `Review: fable`: no public API or default changes here). The library items found in the same review (F46, F50, F55, and the decisions D68, D70, D72, D73) belong to the 06.4 stories; D72's accepted diff is applied there as is, in place (P12); this spec changes no file under `packages/shadcn-table/registry/` and no story file.

### 1.2 Goals

- `lib/routes.ts` lists only routes a page answers: `/about`, `/changelog` and `/roadmap` are gone (F42)
- The `advanced` and `external-toolbar` examples render the sort chip (`ST_SortPopover` `variant="chip"`) before the filter chips while a sort exists, as the stock toolbar does; `custom-top-toolbar` already gets it from the stock toolbar and `custom-headless` has no sort, both unchanged (F51)
- `persistent-view.mdx` says in one paragraph of about 45 words that `persistViewSettings` stores the view in localStorage and restores it on reload; `subheader-filters.mdx` is about 35 words; `custom-headless.mdx` loses its `grid-no-grow` paragraph; the persistent-view preview blurb is one sentence (F52)
- The five editing-crud examples confirm a delete with a shadcn `AlertDialog` (same question, Cancel, destructive Delete) in the three bases; the `alert-dialog` part is installed per base through the docs installer (F53) (P5)
- Every example column with an `icon` has `size` 110 or more, or no explicit `size`; `headerLabelsFit` runs on the filter-variants, editing, detail-panel, column-pinning, faceted-values, row-dragging pages and the customize-components and data-columns guides (F54)
