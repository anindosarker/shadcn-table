# 06: docs

## 1. Architecture

### 1.1 Overview

The docs site describes the 0.7 chrome: subheader filters, a grip for dragging, columns and density buttons, semantic layout, first-column row actions. This spec rewrites every guide whose behaviour v0.8 changes and adds one guide per new surface, from the shipped code of specs 01 to 05, so 0.8.0 and its docs go out together (D33). Workstream E (index, Run plan): branch `v0.8/docs`, worktree `02`, cut from `claude/review` after D merged, one builder, draft PR at the first push (P2), one fable review on the whole diff for correctness against the shipped code (`Review: fable`). Prop tables are hand data; the library copies under `components/ui-<base>/` are regenerated, never edited.

### 1.2 Goals

- Seven new guides, registered in the sidebar, the guides index and the page checks: column icons (D3), filter chips (D9), sort editor (D10), view settings and persistence (D11) (D36), overflow tooltip (D17), scroll cues (D22), tint tokens (D23); the drag animation and locked columns join the column ordering guide (D20) (D21) (D37)
- Every guide whose behaviour changed is rewritten from the shipped code: column actions, column filtering, column ordering, column grouping, column pinning, column resizing, column size, display columns, row actions, pagination, density toggle, column hiding, toolbar customization, global filtering, full screen, sticky header, virtualization, customize components, customize icons, localization, state management, row pinning, detail panel, usage, best practices, and the `st-components` API page
- The prop tables list every new option, column option and state slice with its shipped default; the hard-coded counts in the page checks follow
- One new example, `persistent-view`, in all three bases, with its example page and registry items; no existing example or item is renamed or removed (P5)
- Acceptance: programmatic, `check-pages.mjs --base <base>` exits 0 per base against the agent's own dev server; docs `types:check`, `lint` and `build` exit 0; `node reference/06-check.mjs` (committed by this spec) exits 0: every option name in `reference/01-surface.json` appears in `lib/prop-tables/tableOptions.ts` or `columnOptions.ts`, every new guide slug appears in `content/docs/guides/meta.json`, `lib/routes.ts` and one page-check cluster, and no guide contains the strings `grid-no-grow` as a default, `Move` as a drag handle, or `Show/Hide columns` as a toolbar button except where an explicit option is shown (P6)

#### 1.6.2 New guides

Each guide: what the user sees, the option that turns it off or changes it, the column option where one exists, the localization and icon keys it uses, one live example (an existing example where the stock look shows it, else `persistent-view`).

- `column-icons`: `columnDef.icon` in the header, chips, picker, columns menu and view settings rows; nothing shipped per type; a custom `Header` still possible (D3)
- `filter-chips`: chips as the default mode, "+ Filter" picker, "Clear filters", the hidden-column chip, the column menu Filter item, `filterChips` state, `columnFilterDisplayMode: 'subheader'` and `'popover'` to go back (D5) (D9)
- `sort-editor`: `enableSortPopover`, rules, drag reorder, "Add sort", "Delete sort", the chip, stacking without a modifier, the menu's Notion rule (D5) (D10)
- `view-settings`: opens with the one-line opt-in for `persistViewSettings`, the key rule (automatic hash, `id`, string), what is stored and what is not, `nonce` for strict CSP, the no-flash reload under server rendering, then the rows, pins and Reset view (D11) (D36)
- `overflow-tooltip`: ellipsis by default, tooltip only when cut off, `wrapText`, `enableCellOverflowTooltip`, `columnDef.overflowTooltip`, `ST_OverflowText` in a custom cell (D17)
- `scroll-cues`: the pinned-edge shadow, hover chevrons, `enableScrollButtons`, `data-overflow-start` / `end`, `scrollLeft` / `scrollRight` keys (D22)
- `tint-tokens`: the four variables, their defaults, the order rule, how to override on an ancestor or through `stTableLayoutProps.className`, why no stylesheet ships (D23) (P8)
- Does NOT document internals (hooks, feature files) beyond the exported names
