# v0.5.x plan

Index. Decisions: [decisions.md](decisions.md); parts implement them and never re-decide.
Previous cycle: [../../v0.4.x/anindosarker/](../../v0.4.x/anindosarker/v0.4.x-plan.md) (v9
architecture, shipped as 0.4.0). Base branch for all work: `claude/review`, merged into
`dev`; `dev` goes to `master` by pull request; releases run on `master`.

## Dependencies

```
01 ──> 02 ──> 03 ──> 04 ──> 05
```

Part 02 can start its scripts once part 01 phase 00 has fixed the folder and item names,
but its gates need part 01 merged. 03 needs 02. 04 needs 03.

## Integration

Each part on its own branch from `claude/review` (`v0.5/aria-tree`, `v0.5/infra`,
`v0.5/stories-docs`), one merge commit into `claude/review` when the part's gates are green.
`CHANGELOG.md` `## Unreleased` written as work lands. Part 04 merges `claude/review` into
`dev`, opens the `dev` to `master` pull request, then runs `pnpm release 0.5.0` on `master`.

## Process rules

Tracker per part (`<part>-tracker.md`), decisions and deviations only. Halt and ask the
owner on: a public API choice not covered by `decisions.md`, more than 3 review bounces, an
unfixable gate, a story that passes on radix and cannot pass on aria, a React Aria part
that lacks a capability the library needs (no equivalent of a Radix part prop the library
uses). Worktrees stay clean. Never kill the shared vite server on `:5273`.
