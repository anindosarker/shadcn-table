# v0.7.x plan

Index. Decisions: [decisions.md](decisions.md) D1 to D34 with the 2026-10-31 addenda; findings: [findings.md](findings.md) F1 to F61 (F21, F22 and F45 left open by the owner). Specs implement them and never re-decide. Released together as 0.7.0.

## Goals

- A Next 16 consumer on default `eslint-config-next`, React 19.3 and Tailwind 4.3 opens the installed library with zero editor errors, warnings, strikethroughs or canonical-class hints (F1 to F13)
- The library repo reports the same zero: `pnpm lint` and `pnpm check:tailwind` run the React Compiler rules, `no-deprecated` and the canonical-class check on every library file (D16) (D17) (D19)
- Shipped source carries no porting history, restated code, stale notes, file-wide suppressions or dead exports (D18 to D20)
- Three files sit in the folders of their kind, nothing else moves (D1)
- Docs: one install command with base, package manager, locale and icon library selectors, an optional short namespace form and a shadcn create section; a base selector on every example toolbar; the headless example explains the spacer column and the full-screen hook (D2) (D3) (D24) (D29) (D30) (D33)
- The bugs from the next-app header demo are fixed and every shadcn part is used as its primitive is designed, inside the current architecture: anchor spans stay, Collapsible stays, no public prop or type removed (D21 to D29)
- Icons follow the project: `shadcn-table-core` plus one edition item per icon library, one `icons.ts` per consumer, Lucide only when chosen (D30)
- Direction classes are logical and shadows follow the theme (D31) (D32)
- All three bases identical in every change; registry output regenerated, docs app copies re-installed

### Halt conditions

- An existing registry item name or hosted path changes: `git diff --name-only` touches `registry.json` with a removed `"name"` line or `public/r/<base>/` loses a file (11 adds `shadcn-table-core` and the editions and re-points dependencies; it renames nothing).
- A shadcn part edit of any kind: `git diff --name-only origin/claude/review..HEAD | grep 'components/ui/[^/]*\.tsx$'` non-empty.
- A public option or type removed: `git diff origin/claude/review..HEAD -- '*/types.ts' '*/index.ts' | grep '^-export'` non-empty without a matching `+export`.
- A GitHub ruleset or repository setting change of any kind.
- An `eslint-disable` without a reason: `grep -rn "eslint-disable" packages/shadcn-table/registry | grep -v -- " -- "` non-empty.
- A workstream edit outside its owned set: `git diff --name-only origin/claude/review..HEAD` lists a file another workstream owns (the two S1 set C and S3 import lines excepted).
- A workstream touches `package.json`, `pnpm-lock.yaml`, `eslint.config.js` or `.github/workflows/` after the foundation (S1's `eslint.config.js` switch excepted).
- The next-app install pre-step (09 1.6.2): `git -C ../test-projects/next-app status --short` is not empty (the repo is tracked and clean at `148addc`).
- A decision that no longer fits: an ATTENTION item, never a silent change.
