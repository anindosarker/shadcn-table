# 10.3: select checkbox alignment

## 1. Architecture

### 1.1 Overview

The select checkbox is the outermost inline-level box in its cell, so it sits on the cell's text baseline and lands differently per base: body cell top offset aria 18.5 px, base 13.5 px in a 53 px cell (centred 16.5); header aria 19, base 12 (F65). D64 fixes the targets: body centred, header on the text line top, the three bases equal. Sub-spec of 10; workstream T9 (index, Run plan): branch `v0.7/select-checkbox-alignment`, pool worktree `../shadcn-react-table.worktrees/01` (P1), from `claude/review`. All three bases; `ST_SelectCheckbox.tsx` is listed in `base-diff.json` and `aria-diff.json`, so the edit is made per base with the wrapper line identical.

### 1.2 Goals

- In the body cell the select control's centre equals the cell's centre within 1 px; in the header cell its top equals the header text line's top (`th` padding-top, 12 px comfortable) within 1 px; base, radix and aria measure the same within 1 px (D64)
- Single-selection radio rows behave the same; the tooltip bubble (D61, D63) still anchors on the control, not on the cell
- No public prop or type changes; `check:bases` green with no new diff-list entry
- Acceptance: the new play tests on `features-selection-examples--selection-enabled` and `--single-selection-radio` measure the first body row's control against its `td` (centre within 1 px) and the header control against its `th` (top equals `th` top plus padding-top within 1 px), green in `test:base`, `test:radix` and `test:aria` (P6)
