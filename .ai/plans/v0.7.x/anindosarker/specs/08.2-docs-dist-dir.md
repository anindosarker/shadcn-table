# 08.2: docs distDir

## 1. Architecture

### 1.1 Overview

`next.config.mjs` resolves `distDir` to `.next-<port>` whenever `PORT` is set and not 5320. `next start -p <port>` sets `PORT` too, so a local `next start` on another port finds no build unless `NEXT_DIST_DIR=.next` is exported (A31, the 0.7.0 gotcha unchanged by 08.1). D54 ties the per-port folder to `next dev` only. Sub-spec of 08; workstream T6 (index, Run plan): branch `v0.7/docs-dist-dir`, worktree `../shadcn-react-table.worktrees/docs-dist-dir`, from `claude/review`; inline lane, main session.

### 1.2 Goals

- `pnpm --filter shadcn-table-docs exec next start -p 5331` after a plain `build` serves the site from `.next` with no `NEXT_DIST_DIR` (D54)
- `PORT=5331 pnpm --filter shadcn-table-docs dev` still builds into `.next-5331` and leaves `tsconfig.json` untouched (D43 kept)
- Acceptance: programmatic. After `pnpm --filter shadcn-table-docs build`, `pnpm --filter shadcn-table-docs exec next start -p 5331` answers `curl -sf -o /dev/null -w '%{http_code}' http://localhost:5331/docs/getting-started/introduction` with `200`; then a 30 s `PORT=5331 pnpm --filter shadcn-table-docs dev` leaves `ls -d apps/shadcn-table-docs/.next-5331` present and `git status --short apps/shadcn-table-docs` empty (P6)

#### 1.6.2 `distDir` under `next dev` only

pnpm sets `npm_lifecycle_event` to the running script's name, so the `dev` script (`package.json:12`) is the one path where it equals `dev`; `next start -p <port>` runs under `start` or no script at all. No script change, no new env var (D54 names both forms; the lifecycle check needs no edit to `dev`).

- Does: `distDir` is `NEXT_DIST_DIR` when set, else `.next-<PORT>` only when `process.env.npm_lifecycle_event === 'dev'` and `PORT` is set and not 5320, else `.next`; the comment at `:7-10` says the per-port folder is a `next dev` rule and `next start -p <port>` reads `.next`
- Does NOT change `typescript.tsconfigPath` (`:16-23`, Next reads it under `dev` and `build`; `next start` never does), `lib/dev-tsconfig.mjs`, the `dev`, `start` or `preview` scripts, rewrites, redirects, MDX or PostHog
