# 08.2: docs dist dir

## 1. Architecture

### 1.1 Overview

`apps/shadcn-table-docs/next.config.mjs` derives `distDir` from `PORT` so a second `next dev` can run beside the one on 5320. `next start -p <port>` also sets `PORT`, so a local `next start` on another port looks for `.next-<port>` and finds no build unless `NEXT_DIST_DIR=.next` is set (A31). D54: the per-port directory applies under `next dev` only. Sub-spec of 08; workstream T6 (index, Run plan): branch `v0.7/docs-dist-dir`, worktree `../shadcn-react-table.worktrees/docs-dist-dir`, from `claude/review`. Docs app only.

### 1.2 Goals

- `pnpm --filter shadcn-table-docs build` then `pnpm --filter shadcn-table-docs exec next start -p 5345` serves the build without `NEXT_DIST_DIR` (D54)
- `PORT=5331 pnpm --filter shadcn-table-docs dev` still uses `.next-5331` and `tsconfig.5331.json` (08.1) beside a running 5320 server
- Acceptance: `curl -s -o /dev/null -w '%{http_code}' http://localhost:5345/docs` prints 200 after the two commands above; `ls apps/shadcn-table-docs/.next-5331` exists after a 20 s `PORT=5331 ... dev` (P6)

### 1.3 Current structure

```
apps/shadcn-table-docs/
├── next.config.mjs:10-14   ← distDir: NEXT_DIST_DIR ?? (PORT && PORT !== '5320' ? `.next-${PORT}` : '.next')
├── lib/dev-tsconfig.mjs    ← 08.1, per-port tsconfig under next dev
└── package.json            ← dev: node lib/dev-tsconfig.mjs && next dev -p ${PORT:-5320}; start: next start -p 5320
```

### 1.4 Target structure

```
apps/shadcn-table-docs/
├── next.config.mjs         ← distDir per port only when NEXT_DEV=1; start ignores PORT
└── package.json            ← dev: NEXT_DEV=1 node lib/dev-tsconfig.mjs && NEXT_DEV=1 next dev -p ${PORT:-5320}
```
