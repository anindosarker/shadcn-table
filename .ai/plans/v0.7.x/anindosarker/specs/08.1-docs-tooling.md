#### 1.6.2 next.config.mjs and the per-port tsconfig

Next appends `<distDir>/types/**/*.ts` to the `include` list of the tsconfig it resolves, so a second dev server with `distDir` `.next-<port>` edits `tsconfig.json`. The second server gets its own ignored tsconfig instead: `typescript.tsconfigPath` is `tsconfig.<port>.json` when `PORT` is set and not 5320, else `tsconfig.json`; the `dev` script creates that file (`{ "extends": "./tsconfig.json" }`) before `next dev` when it is missing. Next then rewrites the ignored copy and the committed file stays byte-identical.

- Does: `typescript.tsconfigPath` from `PORT`; `lib/dev-tsconfig.mjs` writes `tsconfig.<port>.json` if missing; `.gitignore` gets `apps/shadcn-table-docs/tsconfig.*.json` with `tsconfig.json` kept; the `distDir` comment names the per-port tsconfig
- Does NOT change `distDir`, rewrites, MDX, PostHog, `reactStrictMode`, or `tsconfig.json`

**Operations:**

| Operation | Status | Notes |
| --- | --- | --- |
| `typescript.tsconfigPath` | new | `process.env.PORT && process.env.PORT !== '5320' ? `tsconfig.${PORT}.json` : 'tsconfig.json'` |
| `lib/dev-tsconfig.mjs` | new | writes the extends stub when missing; no-op on 5320 |
| `package.json` `dev` | refactor | `node lib/dev-tsconfig.mjs && next dev -p ${PORT:-5320}` |
| `.gitignore` | refactor | ignore `apps/shadcn-table-docs/tsconfig.*.json` |

**Stays unchanged:** `tsconfig.json`, `distDir`, `start` script, `types:check`.
