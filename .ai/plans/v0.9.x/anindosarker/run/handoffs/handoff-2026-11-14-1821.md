## Gotchas

- `SendMessage` and `TaskStop` work when called directly; they need no `ToolSearch`.
- A workflow started before a hold keeps going: stop it with `TaskStop`, then check the main checkout for a half merge.
- A stopped merge workflow may already have pushed its merge commit; look at `origin/claude/review` before relaunching.
- When an expedition script refuses the folder, the lead is converting it: wait and retry, never run a `migrate/` script.
- `mark.py` and `item.py` commit by themselves; pull, then push after them. Pushes get rejected when the lead pushes at the same time: pull `--no-rebase`, push again.
- `pnpm test docs-e2e` picks any free port from 5340 to 5360; give agents a port range and `--url` against their own `next start`.
- After a release, a milestone's changelog block can land inside the released section on merge; it belongs under a new `## Unreleased`.
- Stale git-ignored `packages/shadcn-table/storybook-static` in the main checkout still matches greps for old paths.
- Never switch the shared main checkout off `claude/review`; fast-forward `dev` by `git push origin origin/claude/review:refs/heads/dev`.
