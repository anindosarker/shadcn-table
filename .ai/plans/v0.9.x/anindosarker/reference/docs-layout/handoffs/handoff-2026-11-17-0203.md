## Gotchas

- Build with `pnpm build` in `apps/shadcn-table-docs`, never `npx next build`.
- `/docs/examples` redirects to the first row of `meta.json`. The dev server works that target out at start, so after a reorder or rename of the first row it points at the old page until the server restarts. A built site is not affected.
- The dashed line under a stuck sidebar group label uses a container query that only recent Chrome supports. In Safari and Firefox the label still sticks, likely without the line. Not tested there.
- A guide that shows one example twice repeats the element id `example-<name>`; L28 asks for the fix.
- With the keyboard, Tab passes the whole top bar before it reaches the sidebar's hide and show button, because the top bar comes first in the page.
- The sidebar row "Server-Side Pagination" opens a page titled "React Query Example" at `/docs/examples/react-query`, and "Inline Editing" opens "Editing CRUD Inline Row Example". That is intended for now: the short label is a sidebar label only, set through the `sidebarTitle` frontmatter field. Titles and URLs are card LQ29.
- The example picker's dropdown now shows the new group names as its headings, with full page titles under them.
- Storybook: 81 story files, 652 stories, about 270 with an automated check. Renaming a story group changes its stories' Storybook URLs, so the docs links must be regenerated in the same change (L29).
- `perf-report.md` and `docs-layout-research.md` describe the scrolling examples page and the state of 2026-11-05. The scrolling page is not built; treat both files as history.
