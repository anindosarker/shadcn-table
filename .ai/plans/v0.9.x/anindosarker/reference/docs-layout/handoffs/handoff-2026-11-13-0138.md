## Gotchas

- `npx next build` skips the per-style sheets (`lib/build-styles.mjs`) and the registry steps; the theme selector then 404s. Always use `pnpm build` in `apps/shadcn-table-docs`.
- wt1's `node_modules` were stale (371 type errors in generated files) until `pnpm install --frozen-lockfile`; stale `.next/dev` and `.next-preview/types` broke `types:check` after `app/dev` was removed upstream; delete them and rerun.
- A root section (`root: true`) has no folder index in fumadocs: the index page must be listed explicitly in `meta.json` and renamed "Overview" through the transformer in `lib/source.ts`; the breadcrumb drops the root unless `includeRoot` is set (`components/docs-breadcrumb.tsx`); any code that finds a section through `node.index` must also accept the index as the first child (`components/examples-stack.tsx`).
- fumadocs' `usePathname` sync ignores `replaceState` when the state carries Next's `__NA` / `_N` keys; the scroll-spy strips them (`components/examples-scroll-spy.tsx`).
- Unlayered rules in the docs `global.css` beat Tailwind utilities: `#nd-sidebar a` is scoped to `[role='presentation'] a` so the section tabs keep their own type; never fix such a clash with `!important`.
- The owner's style: square corners, dashed `--docs-dash` borders on every content surface except the table frame; LQ6 lists what still breaks it.
- The owner does not want questions, agent counts or process talk; items in the `# LQ<n>. <sentence>` format, one at a time, options with the recommended one first, ending with `Say "record it" to record it, or add to it.`
