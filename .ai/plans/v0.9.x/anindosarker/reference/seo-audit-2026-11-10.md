## PERCEIVE / ANALYZE summary

- Root cause of zero visibility is **discovery and consolidation**, not page quality.
  1. Google has crawled only the homepage, and docs URLs are unknown to it.
  2. The legacy GitHub Pages docs (`monabbir-ahmmad.github.io/shadcn-react-table/`) still return 200 with no canonical or redirect, and they hold the rankings for "shadcn table", "shadcn data table" and the brand query (sxo agent; verified with curl).
  3. There are no canonicals anywhere, so nothing tells Google the new domain is the preferred copy.
- On-page relevance is weak for the head terms. The homepage title and H1 are just `shadcn-table`, and "shadcn data table" appears 0 times site-wide.
- The content is solid in depth (guides of 700-1,800 words, strong hub linking), but a large share is ported from Material React Table, with 38-53% overlap in 6-word phrases. That is a near-duplicate risk against an established site.
- Dependency chain: sitemap/robots deploy (D50) and canonicals, then legacy-site redirect, then GSC sitemap submit and indexing request, then on-page keyword work and schema, then content differentiation and comparison pages.

## Findings

### Critical

1. **The legacy GitHub Pages docs outrank and duplicate the new domain.**
   - Evidence: `https://monabbir-ahmmad.github.io/shadcn-react-table/` and `/docs/` return 200 with no `rel=canonical` and no meta refresh (curl 2026-11-10). WebSearch shows the legacy site for "shadcn table", "shadcn data table" and the brand query, while shadcn-table.com does not appear.
   - Fix: replace the gh-pages build with per-path redirect stubs (meta refresh 0 plus `<link rel="canonical">` to the matching shadcn-table.com URL). GitHub Pages cannot send a 301, so this is the closest equivalent. Map old paths such as `/docs/installation` to their new paths.
   - How we know it failed: after 4 weeks the legacy URLs are still indexed (`site:monabbir-ahmmad.github.io shadcn-react-table`).
   - Leading indicator: GSC impressions on shadcn-table.com become non-zero.
2. **Docs subtree unknown to Google, 0 impressions in 90 days.**
   - Evidence: GSC URL inspection for `/docs` and `/docs/getting-started` returns "URL is unknown to Google". The performance report is empty.
   - Fix: after D50 ships, submit `https://www.shadcn-table.com/sitemap.xml` in GSC. Request indexing for `/`, `/docs/getting-started/introduction`, `/docs/getting-started/install` and the top guides.
   - Before submitting, verify that `NEXT_PUBLIC_SITE_URL` is set in production. `lib/shared.ts:21` falls back to `http://localhost:5320`, which would put localhost URLs in the sitemap and robots.
   - How we know it failed: the GSC sitemap report shows "Discovered" with 0 indexed after 2 weeks.

### High

3. **No `rel=canonical` on any page** (0 of 104 pages; no `metadataBase` or `og:url` in `app`/`lib`).
   - Fix: set `metadataBase` in the root layout and `alternates.canonical` per page (fumadocs `generateMetadata`).
4. **Trailing-slash duplicates return 200.**
   - Evidence: `/docs/api/table-options/` and `/docs/api/` return 200 with no redirect.
   - Fix: keep the Next.js default `trailingSlash: false` and make sure nothing overrides it, or add a redirect. The canonical from #3 covers the rest.
5. **Homepage title and H1 lack target terms.**
   - Evidence: `/` has `<title>shadcn-table</title>` (12 characters), and "shadcn data table" has 0 occurrences site-wide.
   - Fix: use the title "shadcn-table: shadcn/ui data table built on TanStack Table" and put "data table" in the H1 and the meta description. Also retitle Introduction, Installation and Usage (for example "Install shadcn-table (shadcn/ui data table)").
6. **Docs copy is near-duplicate of Material React Table.**
   - Evidence: 38-53% overlap in 6-word phrases on sampled pages. The `/docs/guides/sorting` description is MRT's with the name swapped, and MRT's "use use" typo appears on `/docs/examples/detail-panel`, `lazy-detail-panel` and `lazy-sub-rows`.
   - Fix: rewrite intros and descriptions around what is shadcn-specific (theming, the CLI copy-in, Base/Radix/Aria variants). Keep the MRT credit.
7. **No structured data anywhere** (0 JSON-LD, microdata or RDFa blocks on 104 pages).
   - Fix: add `WebSite` and `SoftwareSourceCode` (with `sameAs` GitHub/Discord, `codeRepository`, `license`, `author`) to `/`, and `TechArticle` plus `BreadcrumbList` to docs pages. Ready snippets are in the schema scratch notes (summarized below).
8. **Homepage has no `og:image` or `twitter:image`.**
   - Evidence: `twitter:card=summary_large_image` is set with no image. `/opengraph-image` returns 404. Docs pages are fine (`/og/docs/*/image.png` is 1200x630).
   - Fix: add `app/opengraph-image.tsx` or reuse the `/og` generator for `/`.
9. **The introduction page does not match the SERP intent.**
   - Evidence: `/docs` and `/docs/getting-started` redirect with a 307 to `/docs/getting-started/introduction`, which has no code and no demo, while every result that ranks shows a preview and an install command.
   - Fix: add the install snippet and a small live demo to the introduction, and make the `/docs` redirect permanent (308).
10. **No page targets "tanstack table shadcn"** (that SERP is about 50% tutorials).
   - Fix: write a guide called "Build a shadcn data table with TanStack Table".

### Medium

11. **No comparison or alternatives content.**
    - Evidence: `llms-full.txt` has 0 hits for tablecn, material-react-table or "shadcn data-table", and tablecn appears in 4 of 5 target SERPs.
    - Fix: add a `/docs/comparison` page against the shadcn data-table recipe, tablecn and MRT, with a feature matrix.
12. **Weak entity and brand signals.**
    - Evidence: the GitHub repo has 55 stars and empty topics (`topics=[]`). Name collisions exist with `whoisseth/shadcn-table` and npm `react-shadcn-table`. There is no named maintainer, version or stars badge on the site.
    - Fix: add GitHub topics (`shadcn-ui`, `tanstack-table`, `react-table`, `data-table`), a maintainer byline, `sameAs` in JSON-LD, and a version/stars badge.
13. **No freshness signals** (no dates, `<time>`, dateModified or changelog).
    - Fix: turn on the fumadocs git "Last updated" line and add `/docs/changelog`. Feed `lastModified` into `app/sitemap.ts`, which has none today.
14. **Wrong, missing or short meta descriptions.**
    - `/docs/examples/column-pinning` uses the sticky-header description.
    - `/docs/guides/row-pinning` uses the row-selection description.
    - `/docs/api` has none, and `/docs/examples` has 21 characters.
    - Install, usage and introduction descriptions are 39-43 characters, and `/docs/examples/infinite-scrolling` has 205.
    - Fix: write a unique 120-155 character description for each page.
15. **Thin example pages.**
    - Evidence: 35 of 42 example pages are under 200 words (median 154). Examples: `/docs/examples/column-grouping` has 102 words and `/docs/examples/filter-switching` has 104.
    - Fix: add 2-3 sentences on when to use it, plus a link to the matching guide.
16. **Homepage TBT is 1040ms (lab), against 110ms on docs.**
    - Evidence: main-thread work is 4.2s. JS is 775 KB across 38 scripts, with an estimated 250-317 KiB unused.
    - Fix: lazy-load or defer hydration of the below-the-fold demo, and dynamic-import heavy demo deps (PDF export, dnd). The homepage demo also shows "Loading" in the server HTML, so give it static fallback text.
17. **Oversized HTML.**
    - Evidence: `/docs/api/table-options` is 1.94 MB, `/docs/api/column-options` 777 KB and `/docs/getting-started/usage` 274 KB.
    - Fix: trim the RSC payload, for example by splitting the API reference or collapsing prop tables server-side.
18. **Markdown responses vary by `Accept` without declaring it.**
    - Evidence: `Accept: text/markdown` returns `text/markdown`, but `Vary` lists only the rsc headers, so CDNs can serve HTML and Markdown under one cache key.
    - Fix: add `Accept` to `Vary`.
19. **`llms.txt` is not spec-shaped, and `llms-full.txt` contains raw JSX.**
    - `llms.txt` has the H1 `# Docs`, no `>` summary, root-relative links and one empty `- ` bullet.
    - `llms-full.txt` contains about 260 lines of `<OptionsSwitcher>`, `<Cards>` and similar.
    - Fix: use `# shadcn-table`, add a summary line, use absolute `.md` links grouped under H2s, and strip MDX components on export.
20. **Missing security headers.**
    - Evidence: HSTS is sent without `includeSubDomains`. There is no CSP, `X-Content-Type-Options`, `Referrer-Policy` or `Permissions-Policy`.
    - Fix: add `headers()` in `next.config`.
21. **`http://shadcn-table.com/` takes 2 redirect hops** (http apex, then https apex, then https www).
    - Fix: redirect straight to `https://www` in the Vercel domain settings.
22. **Policy for the upcoming robots.txt (D50).**
    - Allow search and answer bots (OAI-SearchBot, Claude-SearchBot, PerplexityBot, Googlebot, Bingbot, Applebot).
    - Allow the training bots too (GPTBot, ClaudeBot, CCBot, Google-Extended, Applebot-Extended), since the project is open source.
    - Do not disallow `/dev`, so its noindex stays visible.
    - Optionally disallow `/api/` and `/og/`.

### Low

- `priority: 1` in `app/sitemap.ts` is ignored by Google; remove it.
- Brand name is spelled two ways: "shadcn-table" in titles and "Shadcn Table" in 94 descriptions. Pick one.
- The "Copy Anchor Link" button text sits inside the `<h2>`, and "On this page" is an H3 on 52 pages. Move the button out of the heading and make the label a non-heading.
- Typos: "use use" (3 pages) and "How to column width" (`/docs/guides/column-size`).
- `/favicon.ico` and `/manifest.webmanifest` return 404 (`/icon.svg` exists).
- Docs HTML has no `<link rel="alternate" type="text/markdown">`, although `.md` URLs work.
- Mobile header nav links are about 20px tall. Pad them to 44px.
- No IndexNow key. Optional; it only helps Bing, Yandex and Naver.

### Passing

- Content is in the initial HTML, with one H1 per page, unique titles, `lang=en` and a viewport tag.
- Real 404 pages carry `noindex`, so there are no soft 404s. Apex-to-www redirect works.
- All 103 URLs in `/llms.txt` return 200, and `/llms-full.txt` and per-page `.md` work.
- AI crawler UAs (GPTBot, ClaudeBot, PerplexityBot) get 200, so there is no WAF block.
- Lab CWV: LCP 1.3s, CLS 0, TTFB 60-100ms. Docs OG images are valid 1200x630 PNGs.
- The GitHub repo homepage field and README link to `https://www.shadcn-table.com`.
