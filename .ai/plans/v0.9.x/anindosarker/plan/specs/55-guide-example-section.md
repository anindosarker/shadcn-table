# 55: Guides get an Example section

Follow the project planning rules: docs/code-of-conduct/planning-guidelines.md, CLAUDE.md:9. Keep the expedition contract.

## 1. Architecture

### 1.1 Overview

First-time visitors reach the guides from the home page tiles and meet no table: a guide shows its live example about five sections down, or not at all. D105 gives every guide an "Example" section right under its intro with the best example for that guide, moves every guide heading up one level, and leaves the guide's writing alone. The owner accepted the format on two sample guides of the preview; this spec applies it to all 46 guides, produces the per-guide checklist the owner signs off before a later release, and removes the sample pages.

This spec uses the preview as the reference only: the pages `column-pinning-new-format-3` and `virtualization-new-format-3` (on `claude/review` after spec 53) are the accepted format, and the `GuideExamples` block arrives with spec 53. Its branches are created from `origin/claude/review`.

### 1.2 Goals

- Every one of the 46 guides has an "Example" section directly under its intro paragraph, showing the best example for that guide (D105).
- A table that was already in a guide is removed only when the same example is now in the Example section and the table is not part of the guide's writing; every other table stays where it is (D105).
- Guide sections are h2 and their sub-sections h3 (D105).
- No guide sentence is reworded (D105).
- An example shown twice on one page has two different element ids (D105).
- `reference/docs-layout/guide-checklist.md` lists every guide on one line: the example its section shows and the table removed, if any (D105). The spec produces it; the owner's approval of it gates a later release, not this merge.
- The five guide comparison pages and `VirtualizationGuideExamples.tsx` are gone.
- Acceptance: programmatic, plus judges on the removals. `grep -L "GuideExamples" apps/shadcn-table-docs/content/docs/guides/*.mdx` prints only `index.mdx`; the heading check of task 3 passes; the diff check of task 4 shows no changed sentence; `pnpm test docs-e2e --base base` green. Three judges read every removed table against the rule of D105 (same example in the Example section, and no sentence of the guide points at the table or builds on it), next to the guide on `origin/claude/review`; a majority "part of the writing" puts the table back.

#### 1.6.2 Guide example block (D105)

`components/example-playground.tsx`, `components/mdx/guide-examples.tsx`, `components/guide-example-switch.tsx`, status `refactor`.

- The first mount of an example on a page keeps the id `example-<name>`; a further mount of the same example on that page gets a different id.
- `GuideExamples` also takes an example that has no example page, by its example folder name. Its toolbar slot then shows the example's name without a link; an example that has a page keeps the name link or the picker of D105.
- Does NOT change the toolbar on example pages, the picker's behaviour, or the playground's look.

**Usage:**

```mdx
<GuideExamples slugs={['column-pinning']} />
<GuideExamples slugs={['row-virtualization', 'column-virtualization']} />
<GuideExamples names={['enable-row-numbers-static']} />
```

#### 1.6.3 Guide pages (D105)

`content/docs/guides/<slug>.mdx`, 46 files, status `refactor`.

- Adds a heading "Example" at the guide's section level and one `<GuideExamples>` block directly under the intro paragraph. Nothing else is in the section.
- The example is the best one for that guide: the guide's own example when it has one, otherwise the example that shows the guide's feature most directly. A guide with several fitting examples lists them in the picker, the plainest first. No guide is left without the section, the six guides without a table included.
- Removes a table already in the guide only under the rule of D105, together with its heading and a sentence that only introduced it.
- Moves every heading up one level: the top-level sections become h2, their sub-sections h3. Lines inside fenced code blocks are not headings.
- Does NOT reword, reorder or delete any other sentence; does NOT change the frontmatter, the "View Extra Storybook Examples" line, or any example page.

#### 1.6.4 Comparison pages removed

- Deletes the five guide comparison pages, their `meta.json` entries and `example-groups/VirtualizationGuideExamples.tsx`; regenerates `example-groups/map.tsx`.

**Stays unchanged:** `content/docs/examples/**`, `examples/**`, `components/example-switcher.tsx`, `components/page-switcher.tsx`, every registry file.
