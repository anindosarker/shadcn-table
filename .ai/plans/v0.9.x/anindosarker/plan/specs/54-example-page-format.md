Follow the project planning rules: docs/code-of-conduct/planning-guidelines.md, CLAUDE.md:9. Keep the expedition contract.

## 1. Architecture

### 1.1 Overview

Screen recordings show visitors landing on an example, not knowing what it is and getting lost in the table. D104 gives every example page a short "Try it" list above the table and a "Related guides" list below it, and leaves the page's own text as it is. The owner accepted the format on three sample pages of the preview; this spec applies it to all 42 example pages and removes the sample pages.

This spec uses the preview as the reference only: the pages `basic-new-format-2`, `detail-panel-new-format-2` and `row-dragging-new-format-2` (on `v0.9/docs-layout` after spec 53) are the accepted format. Its branch is created from `origin/v0.9/docs-layout` and merges into `v0.9/docs-layout` (D109).

### 1.2 Goals

- All 42 example pages follow the page order of D104: title and description, the existing body text word for word, `### Try it` with the `TryIt` list directly above the live example, the live example, `## Related guides` (D104).
- Every Try it step is true in base, radix and aria with the default data, and names the exact on-screen label (D104).
- No example page carries the "View Extra Storybook Examples" line (D104).
- The six comparison pages and the "Format previews" group are gone. The preview suffix helper is then dead code; spec 56 removes it with the Storybook map it rewrites.
- No title, description or existing body sentence changes (D104).
- Acceptance: judged, plus programmatic. Three judges read every Try it step and Related guides line against the four criteria of D104 (wording, no slop, no unnecessary jargon, simple and short enough), a majority fail on one line sends that line back; the three accepted `-new-format-2` pages are the reference for tone and size. Programmatic: the diff check of task 4 shows nothing else; every step was run once in a browser on base and its result seen; `pnpm test docs-e2e --base base` green.

#### 1.6.2 Example pages (D104)

`content/docs/examples/<slug>.mdx`, 42 files, status `refactor`.

- Adds `### Try it` and a `<TryIt>` list of 2 to 4 steps directly above the example tag: one short line each, an action and a few words of result; on-screen labels and typed values in backticks.
- Adds `## Related guides` and a link list below the example: the guide pages for the feature, the guides the page text already links included; every link resolves.
- Removes the "View Extra Storybook Examples" line.
- `basic`, `detail-panel` and `row-dragging` take their steps and guide links from the matching `-new-format-2` page unchanged.
- A step carries a few words of reason only where the visitor would otherwise think the table is broken (D104; the detail panel rows without an address).
- A page whose example is a group of tabs gets steps for its first tab and names the tab.
- For an example that fetches data, steps are chosen whose result does not depend on random or changing data (`app/api/data`).
- Does NOT change the frontmatter, any existing sentence or its order, the example tag, or any guide page.

The pages fall into file sets by sidebar group (Featured and Filtering; Server Data, Pinning and Virtualization; Editing, Grouping and Expanding; Drag and Drop, Export and Customization), which no two builders share.

#### 1.6.3 Comparison pages removed

- Deletes the six `-new-format` pages, the "Format previews" group in `meta.json`, and the `isPreviewPage` skip in `lib/example-pages.mjs`.
- Leaves `lib/examples-entry.mjs` and `lib/storybook-map.ts` alone: spec 56 owns the map and removes the helper there, so the two specs share no file.
- Does NOT touch the guide comparison pages (spec 55).

**Stays unchanged:** `components/mdx/try-it.tsx`, `examples/**`, `content/docs/guides/**`, every registry file.
