## 1. Architecture

### 1.1 Overview

Style, Menu Color and Menu Accent in the theme panel change nothing visible: the docs parts under `components/ui-<base>/` carry no `cn-*` class (0 files in ui-radix, ui-base, ui-aria), while the eight `styles/style-*.css` layers target 444 `.cn-*` selectors and the provider's menu loop looks for `cn-menu-target`. D26 regenerates the parts with the hooks. `shadcn add` cannot emit them: ui.shadcn.com serves the per-part `cn-<part>-<slot>` names already resolved to Tailwind, and the CLI's `transformMenu` strips `cn-menu-target` and `cn-menu-translucent` on install (shadcn 4.22.0 and 4.23.0 both, measured in a worktree). The hooked sources exist for the three bases in shadcn-ui/ui `apps/v4/registry/bases/{radix,base,aria}/ui/` (the files next-app's commit 2f97edd swapped in by hand), so the installer fetches them from a pinned commit instead of the served, resolved parts. Mechanisms, verified in the code: Style is the `style-<name>` class on `<html>` plus the `.cn-*` layers; Menu Color is the provider loop toggling `dark` and `cn-menu-translucent` on `.cn-menu-target` popups (`design-system-provider.tsx:240-292`); Menu Accent is a token swap, `--accent` to `--primary` for `bold` (`lib/design-system/config.ts:411`), consumed by `bg-accent` on menu items.

### 1.2 Goals

- Every part under `components/ui-{radix,base,aria}/` (not `shadcn-table/`) is the hooked source of shadcn-ui/ui at commit `42f3bb63b46a69e52a24bd005cdc9ec15ba7a7b9`, imports rewritten to the docs aliases, generated by `pnpm --filter shadcn-table-docs lib:install <base>` (P9: generated, never hand-edited) (D26).
- Picking a Style changes the look of menus, popovers and buttons on every docs page; Menu Color inverts or makes menus translucent; Menu Accent `bold` turns the focused menu item primary (D26).

- Acceptance: programmatic. `pnpm test docs-e2e --base base` green (every page, with the checks of 1.6.4 on `/docs/guides/view-settings`: a style change alters the open menu's computed style, Menu Color `inverted` puts `dark` on the open menu content, Menu Accent `bold` makes the focused item's background equal `--primary`); the three checks red on the shipped parts first (P11); `pnpm test typecheck --base radix|base|aria`, `pnpm test lint`, `pnpm test validate-repo` green; `grep -L "cn-" apps/shadcn-table-docs/components/ui-<base>/*.tsx` lists only collapsible, separator and spinner (the three sources without hooks).
