## Findings

- Deploy: root `vercel.json` routes host `storybook.*` to the `packages/shadcn-table` build (`storybook:build && storybook:build:base`).
- Live URLs: `https://storybook.shadcn-table.com/` (Radix UI) and `https://storybook.shadcn-table.com/base/` (Base UI). Both return 200.
- Each `index.json` has 400 entries, all `type: story`, 0 `docs` entries. Story IDs are the same in both builds.
- Story ID = `slug(title)--slug(exportName)`, e.g. `features-aggregation-examples--aggregation`. With no docs entries, a group link must open its first story: `?path=/story/<id>`.
- Storybook links that already exist:
  - `apps/shadcn-table-docs/components/mdx/storybook-link.tsx`: `storybookUrl` (radix/base) and `<StorybookLink>`, follows the base selector via `useBase()`.
  - 59 MDX pages end with `View Extra Storybook **<StorybookLink>Examples</StorybookLink>**`. It points to the Storybook root only.
  - `lib/routes.ts:392`: the "Extra Storybook Examples" item on the examples index.
  - `components/dev-home/v12/footer.tsx`: hardcoded `storybookUrl.radix`, ignores the selector.
  - `components/table-of-contents-list.tsx`: tracks clicks with `trackStorybookOpened` (surface `nav`).
  - Analytics surfaces in use: `footer`, `mdx_link`, `nav` (`lib/analytics`).
- No Storybook link in `NAV_LINKS` (`lib/layout.shared.tsx`), in `LINKS` (`components/dev-home/v12/nav.tsx`), or in the docs sidebar (`app/docs/layout.tsx`, which uses `SidebarSection`, `SidebarSeparator`).
