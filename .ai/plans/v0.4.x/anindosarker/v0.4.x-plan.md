## Integration

Each part on its own branch from `dev` (`v0.4/v9-architecture` with worktree
`shadcn-react-table.worktrees/06` for part 01; `v0.4/base-tree`, `v0.4/storybook`,

`.ai/plans/v0.4.0/anindosarker/06-00-comparison.md` on that branch (the file lives at

## Process rules

Tracker per part (`<part>-tracker.md`), decisions and deviations only. Halt and ask the
owner on a public API choice not covered by `decisions.md`, more than 3 review bounces, an
unfixable gate, a finding that contradicts a recorded decision. Worktrees stay clean
(`.git/info/exclude` for build output, no ignore churn). Never kill the shared vite server
on `:5273`.
