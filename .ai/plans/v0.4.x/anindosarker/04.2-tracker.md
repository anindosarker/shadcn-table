## Phase 01: Styles

### Deviations

- Base UI tree: `st-collapsible-down` and `st-collapsible-up` are also used by `ST_LinearProgressBar`, `ST_TableDetailPanel`, `ST_TableHeadCellFilterContainer` and `ST_ToolbarAlertBanner`, not only `ST_GlobalFilterTextField`. Owned by the search field alone, those four would animate only while the search field is mounted. The collapsible keyframes are one exported string per tree, `stCollapsibleKeyframes` in `shared/utils/style.utils.ts` (already a diff file; Radix: right/left, Base UI: down/up/right/left), and every component that animates with them renders `<style href="st-collapsible" precedence="low">`. The linear progress CSS stays a module-level const in `ST_LinearProgressBar`. No new base-diff entries.
- The `<style>` tags sit inside the `Collapsible` root next to `CollapsibleContent`, not in a wrapping fragment, so the diff adds lines without reindenting the components. The root is always rendered, so the rule exists before the indeterminate class or the open state flips.
- Docs app (`app/global.css`, `scripts/install.mjs`): the hand-kept ST keyframes and the `.st-progress-indeterminate` rule are removed, since both installed copies render their own. The installer no longer drops `css` and renames `st-collapsible` (word boundary) to `st-base-collapsible` in the Base UI copy, which covers the keyframe names and the style `href`: keyframe names are global and React keeps one style per href, so the two copies on one page would otherwise collide.
- `install.mdx`: the note says React 19 hoists the tag and React 18 renders it in place, since the prerequisites name React 18.
- `test:base` `Profiled Thousand Rows` (RenderCounts) runs about 15.1 s on `claude/review` and 15.2 s here against a 15 s budget; it timed out under a machine load average of 16 and passed in the full `test:base` run at load 7. Not changed here.
- `check-pages a`: 4 failures on `/docs`, `/docs/getting-started` (redirect target is now introduction) and `/docs/getting-started/install` (`namespace form`, `compatibility sentence`). Same on `origin/claude/review`: the page checks were not updated with the installation page rewrite in `a17f7a02`. Not changed here.
