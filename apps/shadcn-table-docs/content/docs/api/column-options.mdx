This page lists every option you can set on a column definition, typed as `ST_ColumnDef<TData>`. Some come from TanStack Table, such as `accessorKey`, `id`, `size` and `filterFn`, and behave as the TanStack Table docs describe. The rest are shadcn-table's own: per-column features, custom renders such as `Cell`, `Header`, `Filter` and `Edit`, and the `st...Props` options that pass props to the shadcn/ui components of that column only. Many column options share their name with a table option: set it on the table to change every column, and on a column to override it for that one column. The display columns the table creates take the same options through `displayColumnDefOptions`, keyed by their `st-row-*` id.

> Many of the column options you can pass here are the same as the ones that you can pass to the TanStack Table [ColumnDefs](https://tanstack.com/table/latest/docs/guide/column-defs)

Here is a list of all the column options you can specify in a `column` definition.

```jsx
const columns = useMemo(
  () => [
    {
      accessorKey: 'name',
      header: 'Name',
      // All of the options you can specify here
    },
  ],
  [],
);

const table = useShadcnTable({ columns, data });

return <ShadcnTable table={table} />;
```
