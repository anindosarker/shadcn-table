This page lists the methods and properties of the `table` object that `useShadcnTable` returns and that the table passes to callback options and custom renders. Most of them are TanStack Table's own instance APIs, such as `getRowModel`, `setSorting` and `resetColumnFilters`, and work as the TanStack Table docs describe. shadcn-table adds setters for its own states, such as `setDensity`, `setIsFullScreen`, `setEditingRow` and `setShowColumnFilters`, plus `refs` to the table's DOM elements and `options` with the merged table options. Use these methods to drive the table from your own buttons, effects or event handlers instead of keeping a second copy of its state in your own component.

> NOTE: These are NOT the [table options](/docs/api/table-options) for shadcn-table. These are just static methods on a table instance that you can use.

These are the methods available on the `table` instance that is returned from the `useShadcnTable` hook. You can use these methods to interact with the table instance.

```jsx
const columns = useMemo(() => [
  {
    accessor: 'name',
    header: 'Name',
    Cell: ({ cell, table }) => <span onClick={() => table.{/* or maybe here */}}></span>,
  },
], []);

const table = useShadcnTable({
  columns,
  data,
  renderTopToolbarCustomActions: ({ table }) => <Button onClick={() => table{/* or maybe here */}}>Click Me</Button>,
});

const someEventHandler = () => {
  table. //call any of the table instance methods here
};

return <ShadcnTable table={table} />;
```
