In previous versions of `shadcn-table`, you only had the option to use the `<ShadcnTable />` component. Now in version 2, all internal ST components are exported for you to optionally use to build up your own custom table components.

### \<ShadcnTable /\>

[View Source Code on GitHub](https://github.com/anindosarker/shadcn-table/blob/master/packages/shadcn-table/src/components/ui/shadcn-table/ShadcnTable.tsx)

For most use cases, you will probably just use the default `<ShadcnTable />` component.

It accepts table options as props, but it can also simply accept the `table` instance as its only prop instead. You have the choice to use the `useShadcnTable` hook to create the table instance in your own scope or not. Using the `table` prop with the `useShadcnTable` hook is recommended, because it will give you more flexibility as your table features get more complex.

```jsx
import { ShadcnTable, useShadcnTable } from '@/components/ui/shadcn-table';
//...
const table = useShadcnTable({
  columns,
  data,
  enableRowPinning: true,
});
return <ShadcnTable table={table} />; //recommended
```

```jsx
import { ShadcnTable } from '@/components/ui/shadcn-table';
//...
return <ShadcnTable columns={columns} data={data} enableRowPinning />; //passing props instead is possible
```

> Do not pass both a `table` prop and other table options as props. Additional table options passed to the `<ShadcnTable />` component will be ignored if a `table` prop is passed. Either specify all table options in the `useShadcnTable` hook or pass all of them as props to the `<ShadcnTable />` component.

### ST\_\* Sub Components

Shadcn Table now exports all of its internal components. You can use them for your own use cases.

#### Table Components

[View Table Components Source Code on GitHub](https://github.com/anindosarker/shadcn-table/tree/master/packages/shadcn-table/src/components/ui/shadcn-table/table)

##### \<ST_TableLayout /\>

The `<ST_TableLayout />` component is the outermost component of the table. Using this is pretty much the same thing as using the `<ShadcnTable />` component, except that you cannot pass table options as props to it.

The layout component includes UI for the table and the toolbar components.

##### \<ST_TableContainer /\>

The `<ST_TableContainer />` component is the container for the table. It only contains the table ui, but none of the toolbar components.

This is a popular use case for tables that do not want the built-in toolbars, but still want all of the other table features.

##### \<ST_Table /\>

The `<ST_Table />` component contains the `<table>` element, and all of the table head, body, and footer components.

Be aware that using this deep of a component, you will lose out on row virtualization, modal editing, and full screen features. Use the above `<ST_TableContainer />` if you want to use those features.

##### \<ST_TableLoadingOverlay /\>

Shows a loading spinner over the table above the `ST_Table` component when the table is loading.

#### TableHead Components

[View TableHead Components Source Code on GitHub](https://github.com/anindosarker/shadcn-table/tree/master/packages/shadcn-table/src/components/ui/shadcn-table/head)

##### \<ST_TableHead /\>

The `<ST_TableHead />` component contains the `<thead>` element, and all of the table head rows.

##### \<ST_TableHeadRow /\>

The `<ST_TableHeadRow />` is a `<tr>` element that contains all of the table head cells in a row

##### \<ST_TableHeadCell /\>

The `<ST_TableHeadCell />` is a `<th>` element that contains all of the table head cell components. It contains all of the other table head cell components down below depending on which features are enabled.

##### \<ST_TableHeadCellColumnActionsButton /\>

A button that opens up the column actions menu.

##### \<ST_TableHeadCellSortLabel /\>

The Sort Icon Button and Label next to a table header

##### \<ST_TableHeadCellFilterLabel /\>

The Filter Icon Button and Label next to a table header

##### \<ST_TableHeadCellGrabHandle /\>

The Grab Handle Icon Button next to a table header used for column dragging

##### \<ST_TableHeadCellResizeHandle /\>

The Resize Handle Icon Button next to a table header used for column resizing

##### \<ST_TableHeadCellFilterContainer /\>

The Filter Container that contains the filter input and filter actions

#### TableBody Components

[View TableBody Components Source Code on GitHub](https://github.com/anindosarker/shadcn-table/tree/master/packages/shadcn-table/src/components/ui/shadcn-table/body)

##### \<ST_TableBody /\>

The `<ST_TableBody />` component contains the `<tbody>` element, and all of the table body rows. It has the ability to render multiple table bodies, depending on if static row pinning features are enabled and used.

##### \<ST_TableBodyRow /\>

The `<ST_TableBodyRow />` is a `<tr>` element that contains all of the table body cells in a row.

##### \<ST_TableDetailPanel /\>

A row and all column-spanning row for rendering detail panels for a row.

##### \<ST_TableBodyCell /\>

The `<ST_TableBodyCell />` is a `<td>` element that surrounds the cell value or custom `Cell` render.

##### \<ST_TableBodyCellValue /\>

Renders the value of a cell. This is a popular component to use as an alternative to TanStack Table's `flexRender` method. It renders everything inside of the `<td>`, but not the `<td>` itself.

##### \<ST_TableBodyRowGrabHandle /\>

A button for grabbing a row for dragging.

##### \<ST_TableBodyRowPinButton /\>

A button or buttons for pinning a row.

#### TableFooter Components

[View TableFooter Components Source Code on GitHub](https://github.com/anindosarker/shadcn-table/tree/master/packages/shadcn-table/src/components/ui/shadcn-table/footer)

##### \<ST_TableFooter /\>

The `<ST_TableFooter />` component contains the `<tfoot>` element, and all of the table footer rows.

##### \<ST_TableFooterRow /\>

The `<ST_TableFooterRow />` is a `<tr>` element that contains all of the table footer cells in a row.

##### \<ST_TableFooterCell /\>

The `<ST_TableFooterCell />` is a `<td>` element that surrounds the cell value or custom `Footer` render.

#### Input Components

[View Input Components Source Code on GitHub](https://github.com/anindosarker/shadcn-table/tree/master/packages/shadcn-table/src/components/ui/shadcn-table/inputs)

##### \<ST_EditCellTextField /\>

The textfield component for editing a cell value that can either show in a modal or table cell.

##### \<ST_GlobalFilterTextField /\>

The search textfield component for global filtering.

##### \<ST_FilterTextField /\>

The textfield component for filtering a column. A somewhat comprehensive component that can be a textfield, select, multi-select, or date picker.

##### \<ST_FilterCheckbox /\>

The checkbox component for filtering a column by boolean values.

##### \<ST_FilterRangeSlider /\>

The range slider component for filtering a column by a range of numbers.

##### \<ST_FilterFilterRangeFields /\>

A Container component that will render two ST_FilterTextField components for filtering in a range (min and max).

##### \<ST_SelectCheckbox /\>

A checkbox component for selecting a row or selecting all rows from the table header.
