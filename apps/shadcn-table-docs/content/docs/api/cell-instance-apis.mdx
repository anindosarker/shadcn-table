This page lists the methods and properties of the `cell` object that shadcn-table passes to column renders such as `Cell` and to callback options such as `stTableBodyCellProps`. A cell is where one row meets one column, so it is the place to read a single value with `cell.getValue()`, reach its `cell.row` and `cell.column`, or check whether it is grouped or aggregated. These come from TanStack Table's cell APIs, so the TanStack Table docs describe the same methods. Use the row and column instance pages for the methods one level up, and the table instance page for the methods that act on the whole table.

<br />

Every cell provides a `cell` object that can be used in many props or column definitions that lets you have access to a cell's information and methods.

You can access and use a `cell` object in quite a few places, but here are some of the most common:

```jsx
const columns = [
  {
    accessorKey: 'username',
    header: 'Username',
    //you can access a cell in many callback column definition options like this
    stTableBodyCellProps: ({ cell }) => ({
      onClick: () => {
        console.log(cell.getValue(), cell.id);
      },
    }),
    //or in the component override callbacks like this
    Cell: ({ cell }) => {
      return <div>{cell.getValue()}</div>;
    },
  },
];

const table = useShadcnTable({
  columns,
  data,
  //or in callback props like this
  stEditTextFieldProps: ({ cell }) => ({
    disabled: cell.getValue() === 'admin',
  }),
});
```

> NOTE: These are NOT [props](/docs/api/table-options) or [column options](/docs/api/column-options) for shadcn-table. These are just static methods on a cell instance that you can use.
