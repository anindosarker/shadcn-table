This page lists the methods and properties of the `column` object that shadcn-table passes to callbacks such as `stTableHeadCellProps`, `Header` and `Filter`, and that `table.getColumn(id)` returns. A column instance is the live form of one column definition: `column.columnDef` holds the options you wrote, and the methods read or change that column's sorting, filters, size, pinning, grouping and visibility. These are TanStack Table's column APIs, so the TanStack Table column docs describe them too. Change a column through these methods rather than by editing its definition, so the table state stays the single source of truth.

> NOTE: These are NOT [column options](/docs/api/column-options) for shadcn-table. These are just static methods on a column instance that you can use.

Each column has a `column` instance object associated with it that can be accessed in callback props and other places in the table.

You can access and use a `column` instance in quite a few places, but here are some of the most common:

```jsx
const columns = [
  {
    accessorKey: 'username',
    header: 'Username',
    //you can access a column instance in many callback functions in a column definition like this
    stTableHeadCellProps: ({ column }) => ({
      style: {
        color: column.getIsSorted() ? 'red' : 'black',
      },
    }),
    //or in the component override callbacks
    Header: ({ column }) => <div>{column.columnDef.header}</div>,
    Cell: ({ cell, column }) => (
      <span
        style={{
          backgroundColor: column.getIsGrouped() ? 'green' : 'white',
        }}
      >
        {cell.getValue()}
      </span>
    ),
  },
];

const table = useShadcnTable({
  columns,
  data,
  //or in callback props like this
  stTableBodyCellProps: ({ column }) => ({
    style: {
      boxShadow: column.getIsPinned() ? '0 0 0 2px red' : 'none',
    },
  }),
});
```
