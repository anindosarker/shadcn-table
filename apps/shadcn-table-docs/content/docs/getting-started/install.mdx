<Steps>

<Step>

### Initialize shadcn/ui

Skip this if the project already uses shadcn/ui. The table needs shadcn/ui on the Radix UI or Base UI base, Tailwind CSS v4 and React 18 or newer; React Aria is not supported. Pick your base with the Radix UI | Base UI tabs: the switch in the header does the same for the whole site, the examples included.

<InitCommand />

</Step>

<Step>

### Add shadcn-table

Copies the table source into `components/ui/shadcn-table/` and installs the shadcn/ui parts and npm packages it needs, in the edition for the selected base. Run it again with `--overwrite` to update.

<InstallCommand />

Or register the registry once and add items by name. `{style}` stands for the `style` in your `components.json` (`radix-nova`, `base-sera`, ...), so this form picks the base on its own.

<NamespaceCommand />

</Step>

<Step>

### Import

```tsx
import { ShadcnTable, useShadcnTable } from '@/components/ui/shadcn-table';
```

Columns, data and the hook: [Usage](/docs/getting-started/usage). Letting an agent do all of this: [AI Agent Setup](/docs/getting-started/agents). Every [example](/docs/examples) renders, shows its source and installs for the selected base.

</Step>

</Steps>
