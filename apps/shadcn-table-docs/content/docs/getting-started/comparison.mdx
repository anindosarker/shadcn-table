Four common ways to build a data table in a React project, side by side. Each cell states only what the project's own public documentation or repository shows on 2026-11-10; "not documented" means we found no mention, not that the feature is missing. Corrections are welcome on [GitHub](https://github.com/anindosarker/shadcn-table/issues).

## Feature matrix

| | shadcn-table | tablecn (Dice UI) | Material React Table | shadcn/ui data-table recipe |
| --- | --- | --- | --- | --- |
| Install model | Copied source, shadcn registry (`shadcn add`) | Copied source, shadcn registry (`shadcn add "@diceui/data-table"`) | npm package (`material-react-table`) | A guide; you write the code |
| Base libraries | Base UI, Radix UI, React Aria | Base UI, Radix UI | Material UI | Base UI, Radix UI, React Aria |
| Sorting | Built in | Built in | Built in | Covered in the guide |
| Filtering | Built in, several filter modes | Built in, advanced filter menus | Built in | One search input in the guide |
| Grouping and aggregation | Built in | Not documented | Built in | Not covered |
| Column and row pinning | Built in | Column pinning | Built in | Not covered |
| Virtualization | Built in | Data grid: rows and columns | Built in | Not covered |
| Editing | Built in | Data grid: in-place cell editing | Built in | Not covered |
| Export | Not built in; CSV and PDF examples | Not documented | Not built in; examples | Not covered |
| i18n | 39 languages | Data grid: RTL support | 38 locales | RTL guide |
| Styling | Your shadcn/ui components and Tailwind CSS | shadcn/ui components and Tailwind CSS | Material UI theme, `sx` and `mui*Props` | shadcn/ui `Table` and Tailwind CSS |
| TanStack Table version | v9 | v9 (`^9.2.4` in the repository) | v8 (`8.20.6`) | v9 |
| License | MIT | MIT | MIT | MIT (shadcn/ui) |

## Which one fits

Pick the **shadcn/ui data-table recipe** when the table is small and you want to own every line: it shows sorting, a search box, pagination, column visibility and row selection on top of TanStack Table, and you add the rest yourself. Pick **tablecn** when you want server-driven filtering in the URL with Notion or Linear style filter menus, or a spreadsheet-like data grid. Pick **Material React Table** when your app already uses Material UI: its feature set is close to shadcn-table's, and it styles through the Material UI theme rather than shadcn/ui. Pick **shadcn-table** when your app uses shadcn/ui and you want those features from one hook, rendered through your own components on Base UI, Radix UI or React Aria. See [TanStack Table with shadcn/ui](/docs/guides/tanstack-table-with-shadcn-ui) for how it is put together.
