shadcn-table can copy a cell's value to the clipboard on click. Set `enableClickToCopy` on a column, or on the table for every column; the cell then renders `ST_CopyButton`, a shadcn/ui `Button` around the value that shows for a few seconds that the value was copied. Pass `stCopyButtonProps` to change its classes or handlers.

### Enable Click to Copy Per Column

Most likely, there will just be a couple columns that you want to enable click to copy for. You can do this by setting the `enableClickToCopy` option to `true` per column on the column definition.

```tsx
const columns = [
  //...
  {
    accessorKey: 'email',
    header: 'Email',
    enableClickToCopy: true,
  },
  //...
];
```

### Enable Click to Copy For All Cells

Alternatively, you can enable click to copy globally by setting the `enableClickToCopy` table option to `true`. You could then opt out per column by setting the `enableClickToCopy` option to `false` on the column definition.

```tsx
const table = useShadcnTable({
  columns,
  data,
  enableClickToCopy: true,
});
```

### Customize Copy Buttons

The click to copy feature is built on top of the shadcn/ui Button component. You can customize the copy button by passing in the `stCopyButtonProps` table or column option.

```tsx
const table = useShadcnTable({
  columns,
  data,
  enableClickToCopy: true,
  stCopyButtonProps: {
    className: 'w-full justify-start',
  },
});
```
