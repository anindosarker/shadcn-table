Shadcn Table uses [Lucide icons](https://lucide.dev) by default for all of its internal icons.

If you need to, you can customize and replace some or all of the icons with your own custom icons. You can either use other Lucide icons or icons from a completely different library.

### Icon editions

The table ships one edition per icon library: Lucide (`shadcn-table`), Tabler, Phosphor, Hugeicons and Remix Icon (`shadcn-table-<library>`). Each one installs the same `icons.ts` with that library's icons and adds only its icon package. To switch, pick the library and run the command with `--overwrite`:

<InstallCommand overwrite />

The previous icon package stays in `package.json`: remove it with your package manager when nothing else uses it. The docs examples use Lucide for their own buttons; swap those imports for your set.

The `icons` option below overrides single icons on any edition.

Every edition maps every icon key. Where a library has no match for a Lucide glyph, its edition uses the closest icon instead and says so in a comment in its `icons.ts` (for example the view settings icon, the sticky header and alternating rows toggles, and in some editions the density icons). The three grid line icons (`GridLinesAllIcon`, `GridLinesRowsIcon`, `GridLinesColumnsIcon`) are drawn by the library itself (`ST_GridLinesAllIcon`, `ST_GridLinesRowsIcon`, `ST_GridLinesColumnsIcon`) and are the same in every edition.

### Icon Keys for the Toolbar and Column Menu

Besides the long-standing keys, these keys draw the chrome of the column menu, the filter chips, the sort editor, the view settings panel and the scroll cues (Lucide defaults in brackets):

- `AddIcon` (`Plus`): "+ Filter" and "Add sort"
- `DeleteIcon` (`Trash2`): delete all filters, remove a sort rule, "Delete sort"
- `SwapVertIcon` (`ArrowUpDown`): the sort button and the sort chip
- `ArrowUpwardIcon` (`ArrowUp`): the ascending sort arrow and Sort ascending (with `ArrowDownwardIcon`, `ArrowDown`)
- `ExpandMoreIcon` (`ChevronDown`): the column menu chevron and the chip caret
- `LockIcon` (`Lock`): locked columns and the Fixed position item
- `PushPinIcon` (`Pin`) and `PushPinOffIcon` (`PinOff`): pin items, unpin, and the view settings pin toggles
- `SettingsIcon` (`Settings2`): the view settings button
- `ViewColumnIcon` (`Columns3`): the Columns row
- `DensitySmallIcon`, `DensityMediumIcon`, `DensityLargeIcon` (`Rows4`, `Rows3`, `Rows2`): the density row and button
- `WrapTextIcon` (`WrapText`) and `SingleLineIcon` (`ArrowRightToLine`): Wrap cell text off and on
- `GridLinesNoneIcon` (`Square`), `GridLinesRowsIcon`, `GridLinesColumnsIcon`, `GridLinesAllIcon`: the grid lines row
- `StickyHeaderOnIcon` (`PanelTop`) and `StickyHeaderOffIcon` (`PanelTopDashed`)
- `StripedOnIcon` (`GapVertical`) and `StripedOffIcon` (`SquareCenterlineDashedVertical`): Alternating row colors
- `RowNumbersOnIcon` (`ListOrdered`) and `RowNumbersOffIcon` (`List`)
- `RestartAltIcon` (`RotateCcw`): Reset view
- `ChevronLeftIcon` and `ChevronRightIcon` (`ChevronLeft`, `ChevronRight`): the scroll cues

Column-type icons (a calendar for dates, a hash for numbers) are not icon keys: set them per column with `columnDef.icon`, see the [Column Icons Guide](/docs/guides/column-icons).

### Replace with Custom Icons

To replace a default icon, specify the icon in the `icons` table option. You should get TS hints for the name of the icons you can replace, but you can also consult [this source file](https://github.com/anindosarker/shadcn-table/blob/master/packages/shadcn-table/registry/radix/components/ui/shadcn-table/icons.ts) for a list of all the icons you can replace.

```jsx
<ShadcnTable
  columns={columns}
  data={data}
  icons={{
    //change sort icon, connect internal props so that it gets styled correctly
    ArrowDownwardIcon: (props) =>  <FontAwesomeIcon icon={faSortDown} {...props} />,
    SearchIcon: () => <FontAwesomeIcon icon={faSearch} />,
    SortIcon: (props) => (<FontAwesomeIcon icon={faArrowDownWideShort} {...props} />), //best practice
  }}
```

Some icons have `style` props that get applied to them internally. So, in order to preserve the ability of those Icons to be styled with the correct paddings, margins, or rotations, you should pass in `{...props}` to your custom icon component as a best practice.
