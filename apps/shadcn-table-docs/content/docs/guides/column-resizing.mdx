shadcn-table draws a resize handle, `ST_TableHeadCellResizeHandle`, at the end of each header cell, and column resizing is on by default (`enableColumnResizing`). The widths live in TanStack Table's `columnSizing` state, so you can read or reset them like any other state.

### Initial Column Sizes

Column sizes will behave differently depending on which `layoutMode` you have set.

See the [Column Size Guide](/docs/guides/column-size) for more information on layout modes and how to set initial column sizes properly for you use case.

### Column Resizing Feature

`enableColumnResizing` is the boolean table option that controls the column resizing feature. It is `true` by default.

The resize handle is a full-height hairline on the trailing edge of each header cell. It is invisible at rest, lights up while the pointer is over the header cell, turns to the primary color while dragging, and shows the `col-resize` cursor over the edge. Double-click the handle to reset the column to its default width. While a column's width differs from its default, its column menu also lists a "Reset column size" item.

Set `enableColumnResizing: false` to turn resizing off for the whole table.

```jsx
const table = useShadcnTable({
  columns,
  data,
  enableColumnResizing: false,
});

return <ShadcnTable table={table} />;
```

You can disable specific columns from being resizable by setting the `enableResizing` column option to false in their respective column definition.

### Column Resize Mode

The default `columnResizeMode` is `onChange`, which means that the column resizing will occur immediately as the user drags the column resize handle. If you are running into performance issues because of many other enabled features, you might want to set the `columnResizeMode` to `onEnd` instead. This will make the column resizing only occur after the user has finished dragging the column resize handle and released their mouse.

```jsx
const table = useShadcnTable({
  columns,
  data,
  columnResizeMode: 'onEnd', //instead of the default "onChange" mode
});
```

### Column Growing

Resizing does not change the layout mode. In the default `"grid"` layout, data columns share the spare width of the table in the ratio of their sizes, while display columns and pinned columns keep their set width. While spare width exists, a dragged edge moves a little faster than the pointer, because the column keeps its share of the spare width. Once the columns are wider than the table, every column renders at its set width and the table scrolls sideways.

If you want every column to keep exactly the width you drag it to, set the `layoutMode` to `"grid-no-grow"`.

```jsx
const table = useShadcnTable({
  columns,
  data,
  layoutMode: 'grid-no-grow', //columns keep their set width and do not fill the remaining space
});
```

Alternatively, if you only want certain columns to grow to fill the remaining space, you can set the `grow` column option to `true` in their respective column definitions.

```jsx
const columns = [
  //...
  {
    accessorKey: 'address',
    header: 'Address',
    size: 250,
    grow: true, //allow this column to grow to fill the remaining space
  },
];
```

This is discussed in more detail in the [Column Size Guide](/docs/guides/column-size#column-grow).

### Column Resize Direction

If you are displaying your table in a RTL (right-to-left) language, you can set the `columnResizeDirection` table option to `"rtl"` to make the column resize handle appear on the left side of the column instead of the right side.

shadcn-table does not read the document direction, so set this option explicitly when your table is rendered in an RTL layout.

```jsx
const table = useShadcnTable({
  columns,
  data,
  columnResizeDirection: 'rtl', //instead of the default "ltr" direction
});

return (
  <div style={{ direction: 'rtl' }}>
    {' '}
    {/* app-wide style? */}
    <ShadcnTable table={table} />
  </div>
);
```

### Enable Resizing on Built-in Display Columns

As discussed further in the [Display Columns Guide](/docs/guides/display-columns), you can customize the options of the built-in columns that get generated under the hood by ST by enabling certain features.

Here, we can enable column resizing on the built-in row numbers column by setting the `enableResizing` column option to true in the `displayColumnDefOptions` table option.

```jsx
const table = useShadcnTable({
  columns,
  data,
  displayColumnDefOptions: {
    'st-row-numbers': {
      enableResizing: true, //allow the row numbers column to be resized
      size: 40,
      grow: false, //display columns do not fill the remaining space (the default)
    },
  },
  enableRowNumbers: true,
});

return <ShadcnTable table={table} />;
```
