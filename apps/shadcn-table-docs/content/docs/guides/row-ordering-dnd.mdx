shadcn-table adds a drag handle column, `st-row-drag`, when `enableRowOrdering` or `enableRowDragging` is on, and tracks the dragged and hovered rows in its state. The table does not move your data: in your `onDragEnd` handler you reorder it, move rows to another table, or hand them to other UI in your application.

> This is not the [Sorting Guide](/docs/guides/sorting), which is a different feature.

### Enable Row Ordering

A common use for row drag and drop is to allow users to reorder rows in a table. This can be done by setting the `enableRowOrdering` table option to `true`, then setting up an `onDragEnd` event handler on the `stRowDragHandleProps` table option.

```jsx
const table = useShadcnTable({
  columns,
  data,
  enableRowOrdering: true,
  enableSorting: false, //usually you do not want to sort when re-ordering
  stRowDragHandleProps: {
    onDragEnd: (event, data) => {
      //data re-ordering logic here
    },
  },
});

return <ShadcnTable table={table} />;
```

### Drag and Drop Rows to Other UI or Tables

The drag-and-drop features are not limited to just internally within the same table. You can also use them to drag rows to other UI elements in your application or even to other tables. This can be done by setting the `enableRowDragging` table option to `true` and setting up an `onDragEnd` event handler on the `stRowDragHandleProps` table option to perform whatever logic you want to happen when a row is dropped.
