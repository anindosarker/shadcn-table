Fetching the data for a detail panel only after the user expands the row keeps the first load small, and it is easy to do in shadcn-table. In this example, `renderDetailPanel` renders a component that runs its own [React Query](https://tanstack.com/query/latest) request for the row, so the request starts the moment the panel opens. The data is cached for a while, so closing and reopening the panel shows it at once without another fetch.

The table itself also runs on the server: `manualFiltering`, `manualSorting` and `manualPagination` are set, the `on...Change` callbacks feed the main query, and `rowCount` drives the footer. `stExpandButtonProps` adjusts the expand button, and a loading state shows in the panel while its request runs.

Use a lazy panel when the details are heavy (a history, a list of orders, a chart) and most users open only a few rows. For panels whose data is already in the row, see the [Detail Panel Example](/docs/examples/detail-panel).
