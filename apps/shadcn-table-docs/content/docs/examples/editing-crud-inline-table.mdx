This example builds full CRUD (create, read, update, delete) with shadcn-table using the inline [`"table"`](/docs/guides/editing#row-editing-mode) editing mode: `editDisplayMode: 'table'` with `enableEditing` renders every cell as an input all the time, so users edit values the way they would in a spreadsheet, one cell after another, with no click to enter edit mode first.

The example tracks the changed cells and saves them in one batch from a button added through `renderBottomToolbarCustomActions`. New rows open inline through `createDisplayMode: 'row'` and `onCreatingRowSave`, and `renderRowActions` adds a delete button per row. TanStack Query mutations apply the changes optimistically; hook in your own API calls to save the data to your backend.

Table editing suits small data sets that users fill in or correct in bulk, such as a price list or a settings grid. For large tables it renders many inputs, so pagination stays on. Check out the other editing modes below, and the [editing guide](/docs/guides/editing) for more information.
