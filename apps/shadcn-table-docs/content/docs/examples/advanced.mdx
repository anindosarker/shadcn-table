Here is a more advanced example showcasing Shadcn Table's many features. Features such as row selection, expanding detail panels, header groups, column ordering, column pinning, column grouping, custom column and cell renders, etc., can be seen here.

This example is still only using client-side features. If you want to see an example of how to use Shadcn Table with server side logic and remote data, check out either the [Remote&nbsp;Data&nbsp;Example](/docs/examples/remote) or the [React-Query Example](/docs/examples/react-query).

### Try it

<TryIt>

1. Click the arrow on row 1. A panel with an avatar and a catch phrase opens.
2. Tick two rows and click `Activate`. A dialog names both people.
3. Click `Salary` and choose `Sort descending`. The highest salary comes first.

</TryIt>
