An infinite scrolling table is a table that streams data from a remote server as the user scrolls down the table. This works great with large datasets, just like our [Virtualization Example](/docs/examples/virtualization), except here we do not fetch all of the data at once upfront. Instead, we just fetch data a little bit at a time, as it becomes necessary.

Using a library like [`@tanstack/react-query`](https://tanstack.com/query/v4) makes it easy to implement an infinite scrolling table in Shadcn Table with the `useInfiniteQuery` hook.

Enabling the virtualization feature is actually optional here but is encouraged if the table will be expected to render more than 100 rows at a time.

## Try it

<TryIt>

1. Scroll to the bottom of the table. More rows load and the `Fetched` count below goes up.
2. Click `First Name` and choose `Sort ascending`. The server sends the sorted rows from the top.

</TryIt>
