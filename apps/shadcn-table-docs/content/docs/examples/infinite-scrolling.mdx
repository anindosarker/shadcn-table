An infinite scrolling table loads rows from a server as the user scrolls down. It works well with large data sets, like the [Virtualized Example](/docs/examples/virtualized), except here the data is not fetched all at once upfront: the table fetches a page at a time as it becomes necessary. This example uses `useInfiniteQuery` from [`@tanstack/react-query`](https://tanstack.com/query/v4) and calls `fetchNextPage` from an `onScroll` handler on the table container (`stTableContainerProps`) when the user nears the bottom.

Pagination is off (`enablePagination: false`), and filtering and sorting run on the server (`manualFiltering`, `manualSorting`) so a new query starts from the top whenever they change. `enableRowVirtualization` with `rowVirtualizerOptions` keeps only the visible rows in the DOM; it is optional but encouraged once the table renders more than 100 rows. A count of fetched rows sits in the bottom toolbar.

Use infinite scrolling for feeds and logs where users browse rather than jump to a page.
