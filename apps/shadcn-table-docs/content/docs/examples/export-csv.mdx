shadcn-table does not ship a data export feature, but the table instance gives you every row model you need to build one in a few lines. In this example, the [`export-to-csv`](https://www.npmjs.com/package/export-to-csv) package is wired to buttons placed in the top toolbar through `renderTopToolbarCustomActions`: export all data, all rows after filtering, the rows on the current page, or only the selected rows (`enableRowSelection` is on).

Each button reads a different row model from the table, such as `table.getPrePaginatedRowModel()` or `table.getSelectedRowModel()`, maps the rows to plain objects and hands them to `export-to-csv`. The footer uses `paginationDisplayMode: 'pages'`, and the selection banner sits at the bottom so it does not cover the toolbar.

Use CSV when users want to open the data in Excel, Google Sheets or another tool. If you need native Excel files, a library such as SheetJS fits the same buttons; for a printable file see the [PDF Export Example](/docs/examples/export-pdf).
