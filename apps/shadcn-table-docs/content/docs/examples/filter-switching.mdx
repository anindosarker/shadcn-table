Shadcn Table supports letting users switch between multiple filter modes. Learn more in the full [Column Filtering Feature Guide](/docs/guides/column-filtering).

### Try it

<TryIt>

1. Click `Filter` and choose `First Name`. Its filter mode reads `fuzzy`.
2. Click `fuzzy`, choose `Starts With` and type `M`. Only Micah remains.
3. Click `Filter`, choose `Age` and click its mode. Only `Between`, `Greater Than` and `Less Than` are offered.

</TryIt>
