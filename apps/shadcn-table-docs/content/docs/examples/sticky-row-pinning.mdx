shadcn-table can pin rows and keep them in view while scrolling. This example sets `enableRowPinning` with the default `'sticky'` display mode: a pinned row first stays where it is in the table, and when the user scrolls it out of view, it sticks to the top or the bottom edge instead of leaving the screen. It starts with rows already pinned through `initialState.rowPinning`, and `getRowId` keeps the pins tied to the right records.

The table scrolls in a fixed-height container (`stTableContainerProps`) with a sticky header (`enableStickyHeader`) and pagination off, and `stTableBodyRowProps` styles the rows. Compared with static pinning, sticky pinning keeps the row in its natural place in the data, so its neighbours stay readable.

Use it when users pin a few rows to compare against while scrolling the rest. For rows that move straight to a fixed block, see the [Static Row Pinning Example](/docs/examples/static-row-pinning). Learn more about row pinning in the [Row Pinning Feature Guide](/docs/guides/row-pinning).
