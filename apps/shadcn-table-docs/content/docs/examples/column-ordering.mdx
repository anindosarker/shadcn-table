This example sets one option, `enableColumnOrdering`, and shadcn-table adds a drag handle to every header cell. Dragging a header onto another moves the column there; the new order lives in the `columnOrder` state, so you can read it, control it or save it like any other TanStack Table state. The column visibility menu in the view settings follows the same order.

Turn this on when users scan wide tables and want the columns they care about next to each other, for example moving a status column beside the name. Pair it with `persistViewSettings` (see the [Persistent View Example](/docs/examples/persistent-view)) when the order should survive a reload, or set `initialState.columnOrder` when you only need a different starting order and no dragging.

The drag handles are shadcn/ui buttons from your `components/ui` folder, so they follow your theme and your base library. Learn more about column ordering in the [Column Ordering Feature Guide](/docs/guides/column-ordering-dnd).
