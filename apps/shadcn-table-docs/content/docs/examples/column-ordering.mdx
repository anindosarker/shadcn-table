Shadcn Table has built-in support for column drag and drop re-ordering. Learn more about column ordering in the [Column Ordering Feature Guide](/docs/guides/column-ordering-dnd).

## Try it

<TryIt>

1. Drag the `City` header onto `First Name`. `City` moves to the front.
2. Open `Show/Hide columns` and click `Reset order`. The columns go back to their first order.

</TryIt>
