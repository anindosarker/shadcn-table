You will most likely use a remote data source for your table, and shadcn-table fully supports it. In this example, the data is fetched from a server and also filtered, paginated and sorted there: the table sets `manualFiltering`, `manualSorting` and `manualPagination` so it does not process the rows itself, and passes the column filters, global filter, sorting and pagination state to the request through the `on...Change` callbacks. `rowCount` gives the footer the total.

Loading and error states come from the request: the `showProgressBars` state shows the progress bar while a refetch runs, and `showAlertBanner` with `stToolbarAlertBannerProps` shows an error banner when it fails. `getRowId` keeps row selection stable across pages.

The fetch runs in a `useEffect`, which keeps the example free of extra libraries. Also be sure to check out the [React Query Example](/docs/examples/react-query), which is very similar but uses TanStack Query to handle much of the state management for fetching, caching and refetching, so that you don't need to fetch from a `useEffect` hook.
