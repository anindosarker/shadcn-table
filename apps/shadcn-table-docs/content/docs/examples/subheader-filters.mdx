Set `columnFilterDisplayMode: 'subheader'` to show the column filters in a row under the headers instead of as chips in the toolbar; each text filter carries its mode picker, as filter modes are on by default. Learn more in the [Column Filtering Feature Guide](/docs/guides/column-filtering).
