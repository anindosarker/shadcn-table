---

Set `columnFilterDisplayMode: 'subheader'` to show the column filters in a row under the headers instead of as chips in the toolbar; with `enableColumnFilterModes` each text filter carries its mode picker. Learn more in the [Column Filtering Feature Guide](/docs/guides/column-filtering).
