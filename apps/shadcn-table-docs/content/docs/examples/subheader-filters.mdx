title: 'Subheader Filters Example'
description: 'An example of Shadcn Table which shows the column filters in a row under the headers, with the filter variants and the filter mode picker.'
---

Shadcn Table shows column filters as chips in the toolbar by default. Set `columnFilterDisplayMode: 'subheader'` to get the filter row under the headers back: every filter variant renders in its column, and with `enableColumnFilterModes` each text filter carries its filter mode picker. Learn more in the full [Column Filtering Feature Guide](/docs/guides/column-filtering).
