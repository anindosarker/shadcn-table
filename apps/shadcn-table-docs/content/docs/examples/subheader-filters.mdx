title: 'Subheader Filters Example'
description: 'Show a filter input under every column header with columnFilterDisplayMode: subheader; each text filter keeps its mode picker since modes are on.'
date: '2026-11-10'
---

Set `columnFilterDisplayMode: 'subheader'` to show the column filters in a row under the headers instead of as chips in the toolbar; each text filter carries its mode picker, as filter modes are on by default. The example also opens the filter row from the start through `initialState`, so the inputs are visible before the user clicks anything.

Every filter variant fits in the subheader row: text inputs, selects, ranges and date pickers render with your shadcn/ui components and size themselves to the column. The filter chips in the toolbar are replaced by the inputs, so users see the active filters right where they apply.

Use subheader filters for data-entry and admin screens where users filter constantly and want every filter visible, the way many spreadsheet-like tools work. For dense tables where filters are occasional, see the [Popover Filters Example](/docs/examples/popover-filters). Learn more in the [Column Filtering Feature Guide](/docs/guides/column-filtering).
