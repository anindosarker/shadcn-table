The `enableRowDragging` option adds a drag handle to the start of each row. This example has two tables, Nice List (Dylan, Raquel, Ervin) and Naughty List (Brittany, Branson), and moves a row to the other table when you drop it there. It does not reorder rows inside one table; for that, see the [Row Ordering Example](/docs/examples/row-ordering).

## Try it

1. Press and hold the drag handle at the start of the Dylan row in Nice List (tooltip "Move").
2. Drag it over Naughty List. A dashed pink outline appears around Naughty List.
3. Release. Dylan leaves Nice List and appears as the last row of Naughty List.
4. Drag Brittany from Naughty List and drop her on Nice List. She appears as the last row of Nice List.
5. Drag a row and drop it inside its own table. Nothing changes.
