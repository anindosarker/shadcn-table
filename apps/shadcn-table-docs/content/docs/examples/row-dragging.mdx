Shadcn Table has built-in support row drag and drop features that can be used in a variety of ways. Learn more about row ordering in the [Row Ordering/DnD Feature Guide](/docs/guides/row-ordering-dnd).

### Try it

<TryIt>

1. Drag Dylan by his handle onto `Naughty List`. He moves there.
2. Drag Brittany onto `Nice List`. She moves there.
3. Drop a row inside its own table. Nothing changes.

</TryIt>
