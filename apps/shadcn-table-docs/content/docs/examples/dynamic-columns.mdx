This example shows how to generate column definitions dynamically from remote data after first render using TanStack Query. You may need to manage the `columnOrder` state manually if doing this.

## Try it

<TryIt>

1. Click `Show/Hide columns`. The six columns listed were built from the fetched data.
2. Click `Last Name` and choose `Sort ascending`. The server sorts the rows.
3. Click page `2`. The server sends rows 11 to 20.

</TryIt>
