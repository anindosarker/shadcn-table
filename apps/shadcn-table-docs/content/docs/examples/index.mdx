Each page in this section shows one shadcn-table feature as a working table with its source code. The examples run on the base library you pick in the docs (Base UI, Radix UI or React Aria), use the same shadcn/ui components the install command copies into your project, and link to the guide that explains the options they turn on. The code tab shows the full file, so you can copy it into your app and adjust the columns and data.

Start with the Basic Example to see the defaults, then pick the page closest to your screen: filtering variants and modes, inline or dialog editing, grouping and aggregation, column and row pinning, row and column virtualization for large data sets, server-side data with TanStack Query, or CSV and PDF export.

Most examples also have Storybook stories with more variations of the same feature. The list below links every example page.
