This example uses `renderDetailPanel` to draw a [Recharts](https://recharts.org/) `LineChart` under each row when the row expands. The chart reads its points from `row.original`, so every row gets its own series, and `stTableBodyRowProps` gives the detail panel row its own background so the chart reads as part of the row above it.

Use this pattern when a row stands for something with a history, such as a player with points per game, a product with monthly sales or a service with response times, and a small chart says more than another column would. The panel is plain React, so any charting library works; Recharts is the library shadcn/ui charts are built on, so its look matches the rest of your shadcn/ui components and themes.

The detail panel is the same feature the [Detail Panel Example](/docs/examples/detail-panel) shows with plain text. Keep the chart light: every expanded row mounts its own chart, so a table that opens many rows at once is better served by a lazy panel.
