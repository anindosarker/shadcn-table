The `enableRowDragging` option adds a drag handle to the start of each row. This example has two tables, Nice List (Dylan, Raquel, Ervin) and Naughty List (Brittany, Branson), and moves a row to the other table when you drop it there. It does not reorder rows inside one table; for that, see the [Row Ordering Example](/docs/examples/row-ordering).

### Try it

<TryIt>

1. Drag Dylan by his handle onto `Naughty List`. He moves there.
2. Drag Brittany onto `Nice List`. She moves there.
3. Drop a row inside its own table. Nothing changes.

</TryIt>
