For advanced use cases where you want to be in 100% control of your UI components, you can use Shadcn Table in a more headless way, kind of like how you would use [stock TanStack Table](https://tanstack.com/table/latest/docs/framework/react/examples/basic-use-table).

The power and flexibility here is almost limitless, as you can combine some already built-in Shadcn Table components alongside your own custom components. For the ST components to work properly, all you need to do is pass the `table` object returned from the `useShadcnTable` hook.
