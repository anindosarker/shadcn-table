This example builds full CRUD (create, read, update, delete) with shadcn-table using `editDisplayMode: 'cell'`: with `enableEditing` on, a double-click turns one cell into an input, and leaving the cell saves it. New rows open inline at the top through `createDisplayMode: 'row'` and are saved with `onCreatingRowSave`, while `renderRowActions` adds a delete button per row. Cell actions (`enableCellActions`) and click-to-copy are turned on as well.

The example collects edited cells and saves them in one batch from a button in the bottom toolbar (`renderBottomToolbarCustomActions`), with TanStack Query mutations doing optimistic updates. Hook your own API calls into those mutations to save the data to your backend. Validation runs as each cell loses focus, and the error shows under the input until the value is fixed.

The inline [`"cell"`](/docs/guides/editing#row-editing-mode) mode suits spreadsheet-like screens where users fix one value at a time. Check out the other editing modes below, and the [editing guide](/docs/guides/editing) for more information.
