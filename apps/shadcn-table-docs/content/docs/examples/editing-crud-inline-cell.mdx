Full CRUD (Create, Read, Update, Delete) functionality can be easily implemented with Shadcn Table, with a combination of editing, toolbar, and row action features.

This example below uses the inline [`"cell"`](/docs/guides/editing#row-editing-mode) editing mode, which allows you to edit a single cell at a time. Hook up your own event listeners to save the data to your backend.

Check out the other editing modes down below, and the [editing guide](/docs/guides/editing) for more information.
