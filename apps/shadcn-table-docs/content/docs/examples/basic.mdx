Shadcn Table turns on client-side sorting, search, filtering, pagination and column hiding by default. This table passes only `columns` and `data` (five people with a name, address, city and state), so everything you see is default behavior. For a table with more options set, see the [Advanced Example](/docs/examples/advanced).

## Try it

1. Click the **First Name** header and choose **Sort ascending**. The rows reorder to Jane, Joe, John, Joshua, Kevin.
2. Click the search icon in the toolbar (tooltip "Show/Hide search") and type `Nebraska`. Only the Kevin Vandy and Joshua Rolluffs rows remain.
3. Click the clear button in the search field (tooltip "Clear search"). All five rows return.
