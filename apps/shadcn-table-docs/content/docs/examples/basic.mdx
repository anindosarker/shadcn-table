This is shadcn-table with its defaults: `useShadcnTable` gets `data` and `columns`, and `<ShadcnTable table={table} />` renders the result. Without any other option you get client-side sorting, column filters shown as chips in the toolbar, a global search field, pagination, column hiding, density and full-screen toggles, all rendered with the shadcn/ui components in your `components/ui` folder.

Start here when you want to see what a table looks like before you customize anything, or when you need a quick list view that works on the first try. Each of these features has an `enable...` option to turn it off, and most of them accept props to restyle the parts they render; the [Minimal Example](/docs/examples/minimal) shows the opposite end with nearly everything turned off.

Once the defaults fit, the next step is usually the column definitions: headers, cell renderers, sizes and per-column filter variants. Be sure to check out the [Advanced Example](/docs/examples/advanced) to see how more features can be combined and customized in one table.
