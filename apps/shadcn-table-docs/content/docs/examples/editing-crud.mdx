This example builds full CRUD (create, read, update, delete) with shadcn-table using the default [`"modal"`](/docs/guides/editing#modal-editing-mode) editing mode: with `enableEditing` and `editDisplayMode: 'modal'`, the edit button opens a shadcn/ui dialog with one input per editable column. `createDisplayMode: 'modal'` does the same for new rows, and `renderEditRowDialogContent` and `renderCreateRowDialogContent` lay out the dialog content.

Saving calls `onEditingRowSave` or `onCreatingRowSave` with the values; validation errors per column show under the inputs, and TanStack Query mutations update the table optimistically. The edit and delete buttons come from `renderRowActions`, the create button from `renderTopToolbarCustomActions`.

Modal editing suits records with many fields or with fields too wide for a cell, and it keeps the table layout calm while a user edits. Because the dialog is your shadcn/ui dialog, it follows your theme and focus handling, and you can add any form layout inside it. Check out the other editing modes below, and the [editing guide](/docs/guides/editing) for more information.
