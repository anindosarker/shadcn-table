shadcn-table can scan your data and generate the filter choices for you. This example sets one table option, `enableFacetedValues`, and the column filters fill themselves: the default text filter (`filterVariant: 'autocomplete'`) suggests the values in the column, `'select'` and `'multi-select'` list the unique values as options, and `'range-slider'` takes its minimum and maximum from the data.

The values come from TanStack Table's faceted row models, which shadcn-table turns on when the option is set. They follow the other filters, so the choices narrow as users filter other columns. You can still pass `filterSelectOptions` on a column when you want a fixed list or custom labels.

Use faceted values for client-side data where the set of values is not known ahead of time, such as cities or job titles. With server-side filtering the client sees only one page, so fetch the options from the server instead. Learn more in the full [Column Filtering Feature Guide](/docs/guides/column-filtering).
