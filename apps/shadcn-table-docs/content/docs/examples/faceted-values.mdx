Shadcn Table can scan your data and automatically generate filter autocomplete suggestions, filter select options, or min and max values for your column filters. This is made possible by the faceted values feature from TanStack Table. Learn more in the full [Column Filtering Feature Guide](/docs/guides/column-filtering).

### Try it

<TryIt>

1. Click `Filter`, choose `City` and open `Filter by City`. Only the cities in the table are listed, each with its count.
2. Pick `Richmond`. One row remains.
3. Click `Filter`, choose `State` and open its list. Only `Virginia` is offered: the lists follow the filtered rows.

</TryIt>
