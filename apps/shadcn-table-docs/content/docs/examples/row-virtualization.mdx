This example sets `enableRowVirtualization`, so shadcn-table renders only the rows that are on screen (plus a few around them) through [`@tanstack/react-virtual`](https://tanstack.com/virtual/v3). The table below has **10,000 rows** with pagination off (`enablePagination: false`) and a fixed-height container through `stTableContainerProps`, and filtering, search and sorting stay responsive. `rowVirtualizerOptions` tunes the virtualizer (here `overscan: 5`), and `enableRowNumbers` shows where you are in the list.

Reach for row virtualization when users want to scroll a long list without paging, such as a log, a large export preview or a lookup table. Be sure to also check out the full [virtualization feature guide docs](/docs/guides/virtualization) to learn about both row and column virtualization.

> NOTE: Only enable row virtualization when you render many rows at once. If you show fewer than a couple dozen rows at a time, it adds overhead to every render instead of saving it; it pays off once you render more than 50 or so rows at the same time with no pagination.
