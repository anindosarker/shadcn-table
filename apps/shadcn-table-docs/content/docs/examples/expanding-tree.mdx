shadcn-table can show rows in an expanding tree structure. This example is the simplest version of the feature: each row of data may carry a `subRows` array with its children, which is where `getSubRows` looks by default. With `enableExpanding` on, rows with children get an expand button, and `enableExpandAll` adds one in the header.

The table starts fully open through `initialState: { expanded: true }`. `paginateExpandedRows: false` keeps sub-rows from counting towards the page size, so a page always shows the same number of top-level rows, and `filterFromLeafRows` makes a filter match deep rows and keep their parents visible.

Use this when your data already arrives nested, such as a file tree or a JSON document. You do not have to follow this exact structure; for flat data with parent ids see the [Expanding Parsed Tree Example](/docs/examples/expanding-tree-flat-parse). Learn more about how to customize this in the [expanding sub-rows feature guide](/docs/guides/expanding-sub-rows).
