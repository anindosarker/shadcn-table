Shadcn Table supports displaying column filters in other ways than the default filter chips in the toolbar. This example shows how to only display column filters when the user clicks on the filter icon in the header and then display the filters in a popover. Learn more in the full [Column Filtering Feature Guide](/docs/guides/column-filtering).

## Try it

<TryIt>

1. Click the funnel next to `Gender`. Its filter opens in a popover.
2. Pick `Female`. Only Candice remains.
3. Click outside the popover. It closes and the filter stays on.

</TryIt>
