Shadcn Table supports rendering your own custom filter UI. This can be useful if you want to render your filters in a custom top toolbar, sidebar, or drawer. Learn more in the full [Column Filtering Feature Guide](/docs/guides/column-filtering).

## Try it

<TryIt>

1. Pick `Male` in `Filter by Gender`. Hugh and Leroy remain.
2. Type `Le` in `Filter by First Name`. Only Leroy remains.

</TryIt>
