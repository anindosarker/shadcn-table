Shadcn Table has a few different UI options and behaviors for displaying grouped columns. See the [Column Grouping Guide](/docs/guides/column-grouping) to learn more.

## Try it

<TryIt>

1. Pick `"remove"`. The `State` and `Gender` columns leave the table; the groups stay.
2. Pick `false`. The grouped columns stay in their own places.
3. Click `Gender` and choose `Ungroup by Gender`. The rows group by state only.

</TryIt>
