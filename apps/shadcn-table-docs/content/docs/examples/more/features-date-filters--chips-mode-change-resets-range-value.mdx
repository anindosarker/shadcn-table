### Try it

<TryIt>

1. Click the Joined chip. The editor shows the range in Between and three rows.
2. Open the mode picker and choose Less Than. The value empties and every row shows.
3. Type a date in the box and press Enter, then choose Between. The value empties again.

</TryIt>
