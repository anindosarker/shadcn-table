### Try it

<TryIt>

1. Drag the first row by its `Move` handle onto the third row. It moves there.
2. Drag the `City` header onto `First Name`. `City` now comes before it.
3. Click `Email Address` and choose `Pin to start`. It moves to the start.

</TryIt>
