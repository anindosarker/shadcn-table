### Try it

<TryIt>

1. Read the box under `Joined`. It holds 5 November 2025, 09:00, and the table shows `Eve`.
2. Click the calendar button and click 2 November 2025.
3. The box keeps 09:00 on the new day and the table shows `Ben`, `Cara`, `Dan` and `Eve`.

</TryIt>
