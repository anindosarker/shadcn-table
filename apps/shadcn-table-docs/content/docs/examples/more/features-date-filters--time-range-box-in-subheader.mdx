## Try it

<TryIt>

1. Type 10:00 AM in the first time box and press Enter. Only `Ben`, `Cara` and `Eve` remain.
2. Clear it and type 10:00 AM in the second box, then press Enter. `Ann`, `Dan` and `Finn` remain.
3. Type 9:00 AM in the first box and press Enter. Only `Dan` remains.

</TryIt>
