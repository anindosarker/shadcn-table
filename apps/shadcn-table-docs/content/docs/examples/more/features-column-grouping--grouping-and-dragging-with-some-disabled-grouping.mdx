## Try it

<TryIt>

1. Click `First Name`. Its menu has no `Group by First Name`.
2. Drag the `Last Name` header onto `Drop to group by Last Name`. Rows group.
3. Drag the `First Name` header. No drop zone for grouping shows.

</TryIt>
