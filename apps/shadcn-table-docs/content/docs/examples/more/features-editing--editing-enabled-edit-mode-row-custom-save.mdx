### Try it

<TryIt>

1. Click `Add`. An empty row opens at the top and `Add` turns into `Save`.
2. Click `Cancel` in the new row. The row goes away and `Add` returns.
3. Click `Edit` on row 1. Its cells turn into inputs.

</TryIt>
