## Try it

<TryIt>

1. Click `First Name`. The menu has no `Reset column size` item.
2. Press Escape and click `Phone Number`. The menu shows `Reset column size`.
3. Choose `Reset column size`. The column goes back to its default width.
4. Click `Phone Number` again. The item is gone.

</TryIt>
