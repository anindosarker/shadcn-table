### Try it

<TryIt>

1. Look at the rows. There are no `Edit` buttons.
2. Click `Toggle Editing`. An `Edit` button shows at the start of each row.
3. Click `Edit` on row 1. A dialog opens with the row's values.
4. Click `Cancel`, then `Toggle Editing`. The `Edit` buttons go away.

</TryIt>
