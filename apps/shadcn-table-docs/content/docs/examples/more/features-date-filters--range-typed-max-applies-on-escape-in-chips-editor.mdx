## Try it

<TryIt>

1. Click `Filter`, choose `Joined` and click the range box.
2. Type 11 November 2025 in `Max`. Do not press Enter.
3. Press Escape. The popup closes, the editor stays open, the box reads `... - Nov 11, 2025` and `Eve` hides.

</TryIt>
