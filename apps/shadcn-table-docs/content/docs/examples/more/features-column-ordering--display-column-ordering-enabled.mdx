### Try it

<TryIt>

1. Click `Show/Hide columns`. `Select` and `Actions` each have a `Move` grip.
2. Drag `Actions` by its grip onto `First Name`. The actions column moves there.
3. Click `Reset order`. The actions column goes back to the end.

</TryIt>
