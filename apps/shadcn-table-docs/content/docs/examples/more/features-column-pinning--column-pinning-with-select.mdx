## Try it

<TryIt>

1. Tick the checkbox of the first row. The row is selected.
2. Open the `City` column menu and choose `Pin to start`. It moves before `First Name`.
3. Open the `City` column menu and choose `Unpin`. It goes back before `State`.

</TryIt>
