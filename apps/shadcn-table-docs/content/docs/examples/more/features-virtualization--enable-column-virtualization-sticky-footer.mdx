## Try it

<TryIt>

1. Look at the bottom. `First Name`, `Middle Name` and `Last Name` show as footers.
2. Set `Rows per page` to `50` and click `Toggle full screen`. The table fills the window.
3. Scroll down through the rows. The footer row stays at the bottom of the table.

</TryIt>
