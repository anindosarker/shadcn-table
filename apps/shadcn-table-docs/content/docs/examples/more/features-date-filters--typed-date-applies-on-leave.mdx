### Try it

<TryIt>

1. Click the date box under `Joined` and type 10 October 2025. All six rows stay.
2. Click the calendar button, then press Escape. All six rows still stay.
3. Click a row in the table. Now the table shows `Ben`, `Cara`, `Dan` and `Eve`.

</TryIt>
