## Try it

<TryIt>

1. Tick the box on the first row. `1 of 15 row(s) selected` covers the headers.
2. Tick the box in the banner. It reads `10 of 15 row(s) selected`.
3. Click `Clear selection`. The column headers come back.

</TryIt>
