## Try it

<TryIt>

1. Hover the first table. A `Scroll right` arrow shows at its right edge.
2. Click `Scroll right`. The table scrolls and a `Scroll left` arrow shows.
3. Hover the second table. No arrows show: its columns fit.

</TryIt>
