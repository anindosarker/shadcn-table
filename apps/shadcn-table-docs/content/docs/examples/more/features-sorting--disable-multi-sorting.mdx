---

## Try it

<TryIt>

1. Click `First Name` and choose `Sort ascending`. A `First Name` chip appears.
2. Click `Last Name` and choose `Sort ascending`. The chip now reads `Last Name`.
3. Click `Sort`. The editor has one rule and no `Add sort`.

</TryIt>
