### Try it

<TryIt>

1. Tick the box on row 1. `1 of 15 row(s) selected` shows above the table.
2. Hold Shift and tick the box on row 4. Only rows 1 and 4 are selected.
3. Click `Clear selection`. All boxes clear.

</TryIt>
