## Try it

<TryIt>

1. Click Filter, then Joined. The editor shows one date box in Less Than.
2. Open the mode picker in the editor and choose Between. The box becomes one range box with `Min` and `Max` in its popup.
3. Choose Less Than again. The single date box returns.

</TryIt>
