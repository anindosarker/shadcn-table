## Try it

<TryIt>

1. Hover the density button in the toolbar. It reads `Density: Compact`.
2. Click it. The rows grow taller and it reads `Density: Comfortable`.
3. Click it again. The rows grow taller still: `Density: Spacious`.

</TryIt>
