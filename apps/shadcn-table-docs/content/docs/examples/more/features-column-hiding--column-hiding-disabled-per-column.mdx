### Try it

<TryIt>

1. Click `Show/Hide columns`. `First Name` and `Last Name` cannot be unticked.
2. Click `Hide all`. Only `First Name` and `Last Name` stay.
3. Click `Show all`. Every column comes back.

</TryIt>
