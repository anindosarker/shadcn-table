## Try it

<TryIt>

1. Click `Filter` and choose `Last Name`. The mode reads `fuzzy`.
2. Click `fuzzy` and pick `Starts With`. Type `s` to keep names starting with S.
3. Choose `Age` from `Filter`. `Min` and `Max` fields set a range.

</TryIt>
