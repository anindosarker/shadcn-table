### Try it

<TryIt>

1. Click the three dots on row 1. `Edit` shows above `View Profile`, `Remove` and `Share`.
2. Choose `Edit`. A dialog titled `Edit` opens with the row's fields.
3. Click `Cancel`. The dialog closes.

</TryIt>
