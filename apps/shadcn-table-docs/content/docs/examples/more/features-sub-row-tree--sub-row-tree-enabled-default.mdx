### Try it

<TryIt>

1. Click `Expand all` in the header. Every level opens, in tree order.
2. Click it again (`Collapse all`). Only the top rows remain.
3. Click the arrow on a row with sub-rows. Its sub-rows show right under it.

</TryIt>
