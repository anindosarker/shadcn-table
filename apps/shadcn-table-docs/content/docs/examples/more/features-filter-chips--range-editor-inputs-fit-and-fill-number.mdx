### Try it

<TryIt>

1. Click `Filter` and choose `Distance`. The `Min` and `Max` inputs fit in the editor.
2. Set `Min` to `10` and `Max` to `20`. Only `Lunch ride` remains.
3. Press Escape, then click the `Distance` chip. The editor opens with both values.

</TryIt>
