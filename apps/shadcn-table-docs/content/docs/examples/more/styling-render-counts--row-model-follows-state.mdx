## Try it

<TryIt>

1. Click `Sort desc`, then `Filter P2`. Rows `P25` to `P21` show.
2. Click `Page 2`. `P20`, `P12` and `P02` show.
3. Click the `Expand all` button above the table. Child rows such as `P22-child` show.
4. Click `Reset filters`, then `Group by age`. Five age groups show.

</TryIt>
