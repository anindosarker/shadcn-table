### Try it

<TryIt>

1. Type `Ada` in the `Filter by First Name` field. Ada's row remains at once.
2. Type `Love` in the `Filter by Last Name` field. The filter state waits.
3. After about a second, `Love` joins the filter state above the table.

</TryIt>
