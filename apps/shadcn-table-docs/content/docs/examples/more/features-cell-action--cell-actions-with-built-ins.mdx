### Try it

<TryIt>

1. Right-click a `First Name` cell. The menu shows `Copy`, `Edit`, `Item 1` and `Item 2`.
2. Choose `Edit`. The cell turns into an input.
3. Type a new name and press `Enter`. The cell shows it.

</TryIt>
