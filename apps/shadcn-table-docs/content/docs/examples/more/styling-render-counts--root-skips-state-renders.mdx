## Try it

<TryIt>

1. Click `Go to next page`. The row numbers start at `6`.
2. Click `Column Actions` on `Age` and choose `Sort ascending`. `Age` shows a sort arrow.
3. Click `Show/Hide search` and type `P2`. Only names starting with `P2` remain.
4. Click `Toggle full screen` twice. The table fills the screen, then returns.
