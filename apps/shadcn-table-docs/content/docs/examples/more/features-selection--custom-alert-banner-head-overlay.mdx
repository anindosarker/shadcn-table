## Try it

<TryIt>

1. Tick the first row's box. A blue banner with `Email` and `Remove` covers the headers.
2. Tick the box in the banner. It reads `10 of 15 row(s) selected`.
3. Click the box in the banner again. The selection clears and the headers come back.

</TryIt>
