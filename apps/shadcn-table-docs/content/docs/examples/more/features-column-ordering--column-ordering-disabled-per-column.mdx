### Try it

<TryIt>

1. Click `Show/Hide columns`. `State` has no `Move` grip.
2. Drag `First Name` by its grip onto `State`. Nothing moves.
3. Drag `First Name` onto `City`. It moves; `State` keeps its place.

</TryIt>
