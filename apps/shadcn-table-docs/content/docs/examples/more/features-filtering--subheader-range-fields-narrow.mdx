### Try it

<TryIt>

1. Find the `Age` filter. `Min` and `Max` sit side by side, cut at the column edge.
2. Find the `Birth Date` filter. It is one range box, cut at the column edge the same way.
3. Try to scroll the table sideways. It does not move: the columns fit.

</TryIt>
