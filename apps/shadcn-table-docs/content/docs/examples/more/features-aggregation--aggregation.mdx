## Try it

<TryIt>

1. Click `State` and choose `Group by State`. Each state shows as one row.
2. Read `Age` and `Salary` on a state row. They show `Max by State` and `Average by State`.
3. Click the arrow on a state row. The people in that state show below it.

</TryIt>
