<TryIt>

1. Click the greyed arrow on Ervin's row. Nothing happens: he has no address.
2. Click the arrow on Dylan's row. The panel shows `Address: 261 Erdman Ford`.
3. Click the double arrow in the header (`Expand all`). Raquel's panel opens too.
