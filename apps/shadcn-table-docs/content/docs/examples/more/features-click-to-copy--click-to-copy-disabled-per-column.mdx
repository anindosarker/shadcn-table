## Try it

<TryIt>

1. Hover a `First Name` cell. A `Click to copy` tooltip shows.
2. Click it. The name is copied to the clipboard.
3. Hover an `Email Address` cell. No `Click to copy` tooltip shows: this column does not copy.

</TryIt>
