### Try it

<TryIt>

1. Click the arrow on a state row. Its gender groups hide.
2. Click `Gender` and choose `Ungroup by Gender`. The rows group by state only.
3. Click `Toggle full screen` in the toolbar. The table goes back into the page.

</TryIt>
