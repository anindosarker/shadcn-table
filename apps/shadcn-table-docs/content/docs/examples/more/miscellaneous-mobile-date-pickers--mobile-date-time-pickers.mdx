### Try it

<TryIt>

1. Click the calendar button in the `Birth Date` filter. A calendar opens.
2. Click the clock button in a `Start Time` filter. A clock opens.
3. Pick a `Birth Date`. Only rows with an earlier birth date stay.

</TryIt>
