### Try it

<TryIt>

1. Click `Edit` on row 1 and type `Zelda` in `First Name`.
2. Click `Cancel`. Row 1 keeps its old first name.
3. Edit row 1 again, type `Zelda` and click `Save`. Row 1 shows `Zelda`.

</TryIt>
