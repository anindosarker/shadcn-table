### Try it

<TryIt>

1. Tick the checkbox on the second row, then scroll down. The row stays in view at the top.
2. Tick the `Toggle select all` checkbox in the header. Every row is selected and pinned.
3. Untick the `Toggle select all` checkbox. Every row is unpinned.

</TryIt>
