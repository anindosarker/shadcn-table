### Try it

<TryIt>

1. Click `Filter` and choose `Birth Date`. The filter editor opens.
2. Type `01011990` in the date field. The filter state stays `[]`.
3. Press Escape. The editor closes and the filter state shows `1990-01-01`.

</TryIt>
