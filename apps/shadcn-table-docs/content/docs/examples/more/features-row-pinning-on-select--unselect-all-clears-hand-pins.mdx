### Try it

<TryIt>

1. Go to the next page and click the pin button on Owen. Owen is pinned.
2. Go back and tick the header checkbox. Page 1's rows are pinned with Owen.
3. Untick the header checkbox. Every pin clears, Owen's too.

</TryIt>
