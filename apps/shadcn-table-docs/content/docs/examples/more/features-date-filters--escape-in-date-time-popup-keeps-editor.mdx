## Try it

<TryIt>

1. Click the `Joined` chip above the table, then the calendar button in the box.
2. Click the time box below the calendar and press Escape. The picker closes and the filter editor stays open.
3. Press Escape again. Now the filter editor closes.

</TryIt>
