### Try it

<TryIt>

1. Click `Toggle density`. The line below the table shows `density=comfortable`.
2. Open `View settings` and pin `Sticky header`. A button for it joins the toolbar.
3. Click `Reset view`. Density is `compact` again and the pin is gone.
4. Check the headers. `Priority` is still hidden.

</TryIt>
