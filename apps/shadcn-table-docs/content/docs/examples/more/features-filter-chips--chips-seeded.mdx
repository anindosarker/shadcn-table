### Try it

<TryIt>

1. Click the `Priority fuzzy: High` chip. Its editor opens with the value.
2. Click `Remove filter`. The Priority chip goes; the Status chip stays.
3. Click `Clear filters`. All chips go and all four rows return.

</TryIt>
