### Try it

<TryIt>

1. Click `Show/Hide columns`. `Select` is first in the list and has a `Move` grip.
2. Drag `Select` by its grip onto `City`. The checkbox column moves after `City`.
3. Untick `Select`. The checkbox column hides.

</TryIt>
