### Try it

<TryIt>

1. Click `Filter` and choose `When`. The `Min` and `Max` inputs fit in the editor.
2. Set `Min` to 3 March 2025 and `Max` to 4 April 2025. Only `Lunch ride` remains.
3. Press Escape, then click the `When` chip. The editor opens with both values.

</TryIt>
