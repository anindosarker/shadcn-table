### Try it

<TryIt>

1. Click `Filter` and choose `When`. The range box fits in the editor.
2. Open the box, set `Min` to 3 March 2025 and `Max` to 4 April 2025, and press Enter. Only `Lunch ride` remains.
3. Press Escape twice, then click the `When` chip. The editor opens with the range box inside it.

</TryIt>
