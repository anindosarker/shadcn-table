## Try it

<TryIt>

1. Click `2 sorts`. The editor lists `Status`, then `Name`.
2. Drag the `Name` rule by its handle above `Status`. The rows sort by name first.
3. Click the X on the `Name` rule. The chip reads `Status`.
4. Click `Delete sort`. The chip goes away.

</TryIt>
