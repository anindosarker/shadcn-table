### Try it

<TryIt>

1. Click the calendar button of the first box and click 5 November 2025. The table shows `Dan` and `Eve` at once.
2. Click the second box and type 11 November 2025. The rows do not change while you type.
3. Press Enter. Only `Dan` remains.

</TryIt>
