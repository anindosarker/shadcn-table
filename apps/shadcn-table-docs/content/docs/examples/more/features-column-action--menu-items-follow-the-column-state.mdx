## Try it

<TryIt>

1. Click `First Name`. The menu shows sort, `Filter`, pin and `Hide` items.
2. Press Escape and click `Last Name`. `Sort ascending` is greyed out; `Clear sort` shows.
3. Press Escape and click `Address`. The menu offers `Pin to end` and `Unpin`.
4. Press Escape and click `State`. `Fixed position` shows, greyed out.

</TryIt>
