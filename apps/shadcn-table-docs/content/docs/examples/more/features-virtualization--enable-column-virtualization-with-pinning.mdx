## Try it

<TryIt>

1. Click `First Name` and choose `Pin to start`. It moves to the left edge.
2. Scroll the table sideways. `First Name` stays in view as the columns go by.
3. Click `First Name` and choose `Unpin`. It scrolls with the rest again.

</TryIt>
