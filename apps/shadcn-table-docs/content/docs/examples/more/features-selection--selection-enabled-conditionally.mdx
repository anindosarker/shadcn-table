## Try it

<TryIt>

1. Find a row with an `Age` under 21. Its box is greyed out and cannot be ticked.
2. Tick the box on a row aged 21 or over. The row is selected.
3. Tick the box in the header. Only the rows aged 21 or over are selected.

</TryIt>
