### Try it

<TryIt>

1. Click `Show/Hide columns` and drag `Phone` by its grip onto `First Name`.
2. Look at the table. `Phone` is now the first column.
3. Click `Reset order`. `Phone` goes back to the end of the list.

</TryIt>
