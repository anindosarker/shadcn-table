## Try it

<TryIt>

1. Click the `Status` chip, then open the select. The option list opens.
2. Press Escape. Only the list closes; the editor stays open.
3. Open the select and pick `Done`. Two rows show.
4. Press Escape. The editor closes and the chip shows `Done`.

</TryIt>
