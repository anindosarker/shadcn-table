### Try it

<TryIt>

1. Click `Show/Hide search` and type `Lily`. Only Lily Park stays.
2. Press Escape. The text clears and both rows return.
3. Press Escape again. The field closes.
4. Open it, type `Lily`, click `Show/Hide search`. The field clears and closes.

</TryIt>
