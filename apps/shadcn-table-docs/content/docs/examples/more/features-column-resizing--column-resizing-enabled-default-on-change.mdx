## Try it

<TryIt>

1. Point at the `First Name` header. A thin line shows on its right edge.
2. Drag that line to the right. `First Name` widens as you drag.
3. Open the `First Name` column menu and choose `Reset column size`. The width goes back.

</TryIt>
