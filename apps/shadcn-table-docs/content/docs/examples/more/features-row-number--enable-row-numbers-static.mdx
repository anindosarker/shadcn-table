### Try it

<TryIt>

1. Look at the `#` column. The rows read `1` to `10`.
2. Click `First Name` and choose `Sort ascending`. The numbers still run `1` to `10`.
3. Go to the next page. The numbers continue from `11`.

</TryIt>
