### Try it

<TryIt>

1. Click `Toggle full screen`. The table fills the screen.
2. Click `Show/Hide search` and type `Ma` in `Search`.
3. Move the pointer onto `Mason` and press `Escape`. The search clears; full screen stays.

</TryIt>
