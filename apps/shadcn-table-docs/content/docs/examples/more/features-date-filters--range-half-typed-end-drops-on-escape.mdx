### Try it

<TryIt>

1. Click the Joined filter box, type 10 October 2025 in `Min` and press Enter. `Ann` and `Finn` hide.
2. Type only the day and the month in `Max`, 11 and 11.
3. Press Escape. The popup closes, the box still reads `Oct 10, 2025 - ...` and the same four rows show.

</TryIt>
