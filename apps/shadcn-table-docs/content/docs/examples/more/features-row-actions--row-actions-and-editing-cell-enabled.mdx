### Try it

<TryIt>

1. Click the three dots on row 1. Only `View Profile`, `Remove` and `Share` show.
2. Press Escape, then double-click a `First Name` cell. A text field opens.
3. Type a new name and press Enter. The field closes.

</TryIt>
