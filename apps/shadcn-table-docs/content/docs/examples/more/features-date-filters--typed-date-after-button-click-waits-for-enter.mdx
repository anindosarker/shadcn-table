### Try it

<TryIt>

1. Click the clear button in the date box under `Joined`. All six rows show.
2. Click the date box and type 10 October 2025. All six rows stay while you type.
3. Press Enter.
4. The table shows `Ben`, `Cara`, `Dan` and `Eve`, who joined after that day.

</TryIt>
