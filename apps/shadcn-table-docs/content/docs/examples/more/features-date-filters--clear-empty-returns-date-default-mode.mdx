### Try it

<TryIt>

1. Click the filter mode button in the `Joined` filter and pick `Empty`. The caption says `Filter Mode: Empty`.
2. Click the x on the `Empty` label in the filter.
3. The caption says `Filter Mode: Equals` again, the default of a date column.

</TryIt>
