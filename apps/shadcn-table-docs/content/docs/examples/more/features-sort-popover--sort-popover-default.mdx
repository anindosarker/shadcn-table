### Try it

<TryIt>

1. Click `Sort` and pick `Status`. The rows sort by status.
2. Press Escape. A `Status` chip appears above the table.
3. Click the `Status` chip, then `Add sort` and `Priority`. The chip reads `2 sorts`.

</TryIt>
