## Try it

<TryIt>

1. Right-click a cell in row 1. A menu opens with `Copy`.
2. Press `Escape`, then right-click a cell in row 2. The browser's own menu shows.
3. Right-click a cell in row 3. The table's menu opens again.

</TryIt>
