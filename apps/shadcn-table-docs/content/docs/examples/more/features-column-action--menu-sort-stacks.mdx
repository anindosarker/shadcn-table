### Try it

<TryIt>

1. Click `First Name` and choose `Sort ascending`. The rows sort by first name.
2. Click `Last Name` and choose `Sort descending`. Both columns stay sorted.
3. Click `First Name` and choose `Sort descending`. Only its direction changes.

</TryIt>
