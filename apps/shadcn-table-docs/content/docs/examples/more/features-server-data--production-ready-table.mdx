### Try it

<TryIt>

1. Open the network tab of your browser's developer tools.
2. Click the next page button (`Go to next page`). One request to `/api/users` asks for `page=2`.
3. Open the `First Name` column menu and choose `Sort ascending`. One request asks for `sortBy=firstName:asc` and `page=1`.
4. Click the search button (`Show/Hide search`) and type `Hermann`. One request asks for `search=Hermann`.
5. Click `Filter`, choose `State` and type `geo`. One request asks for `filter=state[$contains]=geo`.

</TryIt>
