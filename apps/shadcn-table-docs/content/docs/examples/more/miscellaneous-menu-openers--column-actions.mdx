## Try it

<TryIt>

1. Click `Column Actions` on `First Name` twice. The menu opens, then closes.
2. Open the menu and press `Escape`. Focus is back on `Column Actions`.
3. Open the menu and choose `Filter`. A `First Name` filter opens, ready to type in.

</TryIt>
