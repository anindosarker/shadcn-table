### Try it

<TryIt>

1. Click `Show/Hide columns`. Each column has a `Move` grip and no checkbox.
2. Drag `Zip` by its grip onto `First Name`. `Zip` moves to the front.
3. Click `Reset order`. The columns go back to their first order.

</TryIt>
