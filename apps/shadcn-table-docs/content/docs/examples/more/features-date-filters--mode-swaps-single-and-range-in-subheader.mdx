## Try it

<TryIt>

1. Click the mode button in the Joined filter and choose Between. One range box replaces the date box and all six rows show.
2. Click the box, type 10 October 2025 in `Min` and press Enter. `Ann` and `Finn` hide.
3. Choose Between Inclusive. The range stays. Choose Less Than. The single date box returns empty.

</TryIt>
