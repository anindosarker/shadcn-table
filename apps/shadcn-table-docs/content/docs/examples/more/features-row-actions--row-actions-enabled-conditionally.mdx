### Try it

<TryIt>

1. Click `Toggle Row Actions`. A three-dot button appears at the end of each row.
2. Click the three dots on row 1. `View Profile`, `Remove` and `Share` show.
3. Press Escape, then click `Toggle Row Actions` again. The buttons go away.

</TryIt>
