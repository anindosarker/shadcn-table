### Try it

<TryIt>

1. Click `Edit` on row 1. A dialog opens with the row's values.
2. Change `First Name`, click `Save`, then `Cancel`. A bar runs above the table.
3. Wait a moment. The bar goes and row 1 shows the new name.

</TryIt>
