## Try it

<TryIt>

1. Click the Joined filter box, type 11 November 2025 in `Max` and press Enter.
2. Type 12 December 2025 in `Min` and press Enter.
3. Press Escape. The popup closes, the ends swap and only `Eve` shows.

</TryIt>
