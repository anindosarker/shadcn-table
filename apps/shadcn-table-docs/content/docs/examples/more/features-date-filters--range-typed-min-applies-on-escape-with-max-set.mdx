### Try it

<TryIt>

1. Click the Joined filter box, type 11 November 2025 in `Max` and press Enter. `Eve` hides.
2. Type 10 October 2025 in `Min`. Do not press Enter.
3. Press Escape. The popup closes, the box reads `Oct 10, 2025 - Nov 11, 2025` and only `Ben`, `Cara` and `Dan` show.

</TryIt>
