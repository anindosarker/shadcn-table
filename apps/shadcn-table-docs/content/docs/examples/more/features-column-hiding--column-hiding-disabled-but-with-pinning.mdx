## Try it

<TryIt>

1. Click `Show/Hide columns`. Each column has pin buttons and no checkbox.
2. Click `Pin to left` beside `Zip`. `Zip` moves to the left edge.
3. Click `Unpin all`. `Zip` goes back to its place.

</TryIt>
