## Try it

<TryIt>

1. Look at the header. `Grouped` and `Location` both span `Address`, `City` and `State`.
2. Drag the right edge of `City`. `City` widens, and both groups widen with it.
3. Click `City` and choose `Sort ascending`. The rows sort by city.

</TryIt>
