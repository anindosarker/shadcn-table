### Try it

<TryIt>

1. Look at the headers. `ID` stays narrow; the name columns fill the width.
2. Drag the right edge of `ID` to the right. `ID` widens; the name columns narrow.
3. Double-click that edge. `ID` goes back to its narrow width.

</TryIt>
