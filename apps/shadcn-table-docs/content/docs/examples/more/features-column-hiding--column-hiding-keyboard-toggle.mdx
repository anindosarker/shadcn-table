### Try it

<TryIt>

1. Click `Show/Hide columns` and use the arrow keys to reach `Last Name`.
2. Press Space. `Last Name` hides and its box clears.
3. Press Enter. `Last Name` shows again.
4. Press Tab. Focus moves to the buttons beside the items.

</TryIt>
