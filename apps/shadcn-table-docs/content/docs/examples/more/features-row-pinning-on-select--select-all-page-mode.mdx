### Try it

<TryIt>

1. Tick the header checkbox. The five rows on page 1 are selected and pinned.
2. Go to the next page. The pinned rows stay above Jackson, Nora and Owen.
3. Go back and untick the header checkbox. The pins clear, page 1 stays.
4. Tick it again, then click `Clear selection`. The pins clear again.

</TryIt>
