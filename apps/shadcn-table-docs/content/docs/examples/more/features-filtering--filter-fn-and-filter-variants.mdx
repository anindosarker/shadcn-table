### Try it

<TryIt>

1. Click `Filter` and choose `Is Active`. A `Filter by Is Active` checkbox shows.
2. Choose `State` from `Filter`, pick `CA` and `TX`. Only those states remain.
3. Choose `Age` from `Filter`. `Min` and `Max` fields set a range.
