## Try it

<TryIt>

1. Click `Filter`, choose `Status`, then the mode button. `Includes any` is checked.
2. Pick `Excludes`. The mode menu closes.
3. Click the input and pick `Done`. The `Done` rows leave the table.

</TryIt>
