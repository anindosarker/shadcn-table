### Try it

<TryIt>

1. Open search and type a last name from the table. The rows change.
2. Click `Show/Hide search` again. The search clears, closes and all rows return.
3. Open search, type a name and press Escape. The text clears and all rows return.
4. Press Escape again. The search box closes.

</TryIt>
