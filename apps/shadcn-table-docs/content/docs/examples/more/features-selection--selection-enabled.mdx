## Try it

<TryIt>

1. Tick the box on row 1. `1 of 15 row(s) selected` shows above the table.
2. Hold Shift and tick the box on row 4. Rows 1 to 4 are selected.
3. Tick the box in the header. All 10 rows on the page are selected.
4. Click `Clear selection`. All boxes clear.

</TryIt>
