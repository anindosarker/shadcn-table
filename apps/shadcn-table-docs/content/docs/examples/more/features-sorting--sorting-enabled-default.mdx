## Try it

<TryIt>

1. Click `First Name` and choose `Sort ascending`. A `First Name` chip appears.
2. Click `Last Name` and choose `Sort descending`. The chip reads `2 sorts`.
3. Click `2 sorts`. The editor lists `First Name`, then `Last Name`.

</TryIt>
