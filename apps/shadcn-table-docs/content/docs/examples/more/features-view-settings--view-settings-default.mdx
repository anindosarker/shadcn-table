## Try it

<TryIt>

1. Open `View settings` and pin `Grid lines`. A `Grid lines` button joins the toolbar.
2. Unpin `Density`. The `Toggle density` button leaves the toolbar.
3. Close the panel and click `Grid lines`. The line below the table changes.
4. In `View settings`, switch on `Row numbers`. A `#` column appears.

</TryIt>
