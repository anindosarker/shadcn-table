### Try it

<TryIt>

1. Click the `First Name` header. The menu shows `Item 1` and `Item 2`.
2. Press Escape and click `Last Name`. The menu shows `Item 2` and `Item 3`.
3. Press Escape and click `Address`. The built-in items come first, then the two items.
4. Press Escape and click `State`. Only the built-in items show.

</TryIt>
