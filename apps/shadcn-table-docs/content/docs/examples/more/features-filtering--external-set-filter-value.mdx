### Try it

<TryIt>

1. Click `Find Joes`. A `First Name` chip joins the toolbar.
2. Click `Find 18-25 Age Range`. An `Age` chip joins it and the ages narrow.
3. Click `Reset Filters`. The chips go and every row returns.

</TryIt>
