### Try it

<TryIt>

1. Click `Add`. An empty row in edit mode opens below the last row of the page.
2. Click `Cancel` in that row. The empty row closes.
3. Click `Edit` on a row, change `First Name` and click `Save`. The new name stays.

</TryIt>
