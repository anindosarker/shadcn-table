## Try it

<TryIt>

1. Look at the top toolbar. The outer pager reads `1-3 of 3`.
2. Look inside any open panel. Its own pager reads `1-5 of 5`.
3. Read the cells. Outer names end in `(3)`, inner names in `(5)`.

</TryIt>
