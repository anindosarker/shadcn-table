### Try it

<TryIt>

1. Hover a row checkbox. The tooltip reads `Toggle select row`.
2. Press Tab to that checkbox. The same tooltip opens, and closes when focus leaves.
3. Hover the `Is Active` filter checkbox. The tooltip reads `Filter by Is Active`.
4. Hover the grouped value `Ohio`. The tooltip reads `State`.

</TryIt>
