### Try it

<TryIt>

1. Find `1-1.000 of 11.111` in the footer.
2. Open `Rows per page` and choose `100`. The footer shows `1-100 of 11.111`.
3. Click page `2`. The footer shows `101-200 of 11.111`.

</TryIt>
