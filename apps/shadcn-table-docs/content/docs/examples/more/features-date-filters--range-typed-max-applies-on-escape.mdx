### Try it

<TryIt>

1. Click the Joined filter box and type 11 November 2025 in `Max`. Do not press Enter. The rows do not change yet.
2. Press Escape. The popup closes, the box reads `... - Nov 11, 2025` and `Eve` hides.
3. The line above the table prints the filter value: it holds the same end as the box.

</TryIt>
