### Try it

<TryIt>

1. Tick the box in the header. The banner reads `10 of 15 row(s) selected`.
2. Go to the next page. Its rows are not selected.
3. Tick the box in the header there. The banner reads `15 of 15 row(s) selected`.

</TryIt>
