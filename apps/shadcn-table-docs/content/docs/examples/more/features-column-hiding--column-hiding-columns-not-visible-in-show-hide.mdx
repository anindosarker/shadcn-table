### Try it

<TryIt>

1. Click `Show/Hide columns`. `First Name` and `Last Name` are not in the list.
2. Close the menu, click `First Name` and choose `Hide`. The column hides.
3. Open `Show/Hide columns` and click `Show all`. `First Name` returns.

</TryIt>
