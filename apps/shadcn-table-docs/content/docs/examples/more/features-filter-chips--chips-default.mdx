### Try it

<TryIt>

1. Click `Filter`, choose `Status` and type `Done`. The chip shows `Status fuzzy: Done`.
2. Click `Clear filters`. The chip goes and all four rows return.
3. Add a `Name` filter, click the `contains` mode button and pick `Empty`.
4. The chip shows `Name is empty`. Click `Remove filter` to drop it.

</TryIt>
