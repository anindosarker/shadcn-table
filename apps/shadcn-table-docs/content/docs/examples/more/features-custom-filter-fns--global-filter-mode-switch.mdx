### Try it

<TryIt>

1. Type `ily` in `Search`. Only Lily remains.
2. Open the search mode menu and pick `Starts With`. The search clears.
3. Type `ily`: no row matches. Type `Li` instead: Lily shows again.
4. Switch the mode to `Contains` and type `ily`. Lily shows again.

</TryIt>
