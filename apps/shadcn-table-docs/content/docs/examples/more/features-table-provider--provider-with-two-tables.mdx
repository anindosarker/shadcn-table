## Try it

<TryIt>

1. Look above the first table. Its count reads `1-2 of 2`.
2. Look in the first table's toolbar. It reads `1-2 of 2` too.
3. Look at the second table. Both of its counts read `1-4 of 4`.

</TryIt>
