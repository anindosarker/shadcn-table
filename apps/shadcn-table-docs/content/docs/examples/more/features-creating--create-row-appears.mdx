### Try it

<TryIt>

1. Click `Add`. An empty row opens at the top with blank name boxes.
2. Type `Zelda` in `First Name` and `Quinn` in `Last Name`.
3. Click `Save`. The empty row closes and Zelda Quinn shows as the last row.

</TryIt>
