## Try it

<TryIt>

1. Read the line under the filter. It says `Filter Mode: Fuzzy`.
2. Type `ack` in `Filter by First Name`. Only Jackson remains.
3. Open the filter mode menu and pick `Starts With`. Jackson is gone.
4. Pick `Contains` from the same menu. Jackson shows again.

</TryIt>
