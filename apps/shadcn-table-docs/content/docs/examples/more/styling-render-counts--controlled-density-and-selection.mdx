### Try it

<TryIt>

1. Click `Toggle density`. The text above the table changes to `spacious`.
2. Click `Toggle density` again. It changes to `compact` and the rows get tighter.
3. Tick the checkbox on `Lily`. `1` shows above the table and the row is highlighted.

</TryIt>
