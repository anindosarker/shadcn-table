## Try it

<TryIt>

1. Open the `Email Address` column menu and choose `Pin to start`. It moves first.
2. Open the `First Name` column menu and choose `Pin to end`. It moves last.
3. Open the `Email Address` column menu and choose `Unpin`. It goes back.

</TryIt>
