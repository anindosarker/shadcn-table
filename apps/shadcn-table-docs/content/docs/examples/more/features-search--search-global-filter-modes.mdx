## Try it

<TryIt>

1. Open search and click `Change search mode`. It lists `Fuzzy`, `Contains`, `Starts With`.
2. Choose `Starts With` and type the start of a first name. Only matching rows stay.
3. Choose `Contains`. The search box clears and all rows return.

</TryIt>
