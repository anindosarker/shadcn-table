### Try it

<TryIt>

1. Double-click a `Last Name` cell. It turns into an input.
2. Type a new name and click outside. The cell shows it.
3. Click `Add`. A new empty row opens with `Cancel` and `Save` buttons.
4. Click `Cancel` in that row. The new row goes away.

</TryIt>
