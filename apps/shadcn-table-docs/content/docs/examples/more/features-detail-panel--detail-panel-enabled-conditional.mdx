### Try it

<TryIt>

1. Click the arrow on a row with `Age` over 50. City, State, Zip and Phone show.
2. Click the greyed arrow on a row with `Age` 50 or under. Nothing opens.
3. Click the double arrow in the header (`Expand all`). Every row over 50 opens.

</TryIt>
