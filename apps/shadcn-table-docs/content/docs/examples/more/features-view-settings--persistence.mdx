## Try it

<TryIt>

1. Click `Toggle density`. The line below the table shows `density=spacious`.
2. Set `Rows per page` to `20`. The line shows `pageSize=20`.
3. Click `Remount`. The density and rows per page stay as you set them.
4. Open `View settings` and click `Reset view`. The saved view is cleared.

</TryIt>
