### Try it

<TryIt>

1. Click the `Joined` chip above the table. The filter editor opens with a date box.
2. Click the calendar button in the box, then click 2 November 2025.
3. The calendar closes, the editor stays open, and the table shows `Ben` and `Cara`.

</TryIt>
