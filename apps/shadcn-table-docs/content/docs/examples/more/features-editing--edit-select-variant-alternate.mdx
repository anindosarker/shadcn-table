## Try it

<TryIt>

1. Click `Edit` on row 1. The row turns into inputs.
2. Open the `State` dropdown. It lists codes from `AL` to `SC`.
3. Pick `CA`, click `Save`, then `Cancel`. Row 1's `State` reads `California`.
