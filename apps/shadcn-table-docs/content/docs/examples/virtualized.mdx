shadcn-table has built-in virtualization through [`@tanstack/react-virtual`](https://tanstack.com/virtual/v3) that lets you render a large number of rows and columns without the slowdown a large DOM would normally cause. This example sets both `enableRowVirtualization` and `enableColumnVirtualization`, tuned through `rowVirtualizerOptions` and `columnVirtualizerOptions`, and renders **10,000 rows** and over a dozen columns with pagination off; filtering, search and sorting stay responsive.

Column pinning, resizing and row numbers (`enableColumnPinning`, `enableColumnResizing`, `enableRowNumbers`) stay on to show that they keep working with virtualization. Be sure to also check out the full [virtualization feature guide docs](/docs/guides/virtualization) to learn about both row and column virtualization.

> NOTE: Only enable virtualization when you have many rows or columns. If you render fewer than a couple dozen rows at a time, it adds overhead to every render instead of saving it; it pays off once you render more than 50 or so rows at the same time with no pagination, or dozens of columns.
