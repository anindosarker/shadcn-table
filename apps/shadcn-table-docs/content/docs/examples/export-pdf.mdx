Shadcn Table does not have a data exporting feature built-in. However, you can easily integrate your own exporting features.

In the example below, `jspdf` and `jspdf-autotable` are connected to some export buttons in the top toolbar to export table rows to a PDF file that can be downloaded.

## Try it

<TryIt>

1. Click `Export All Rows`. A PDF with all 12 rows downloads.
2. Tick two rows and click `Export Selected Rows`. The PDF holds only those two.

</TryIt>
