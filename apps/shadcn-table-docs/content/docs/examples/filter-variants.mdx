shadcn-table not only has filtering built in, it also has filter variants that do the heavy lifting of picking the right input for each column. This example sets `filterVariant` per column to show them all: `'text'`, `'select'`, `'multi-select'`, `'checkbox'`, `'range'`, `'range-slider'`, `'date-range'`, `'time-range'` and `'datetime-range'`. Each variant renders shadcn/ui inputs from your `components/ui` folder and pairs with a fitting filter function, so a range filter compares numbers and a date range compares dates.

Choose the variant from the data type and from how users think about the column: a select for a short list of statuses, a slider for a bounded number such as age, a date range for timestamps. The variants combine with filter modes, faceted values and the filter display modes (chips, subheader, popover).

There is much more you can do to customize filtering, so be sure to check out the full [Column Filtering Feature Guide](/docs/guides/column-filtering) for more information.
