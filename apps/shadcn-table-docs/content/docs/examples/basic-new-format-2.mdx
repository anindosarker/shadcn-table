Shadcn Table turns on client-side sorting, search, filtering, pagination and column hiding by default. This table passes only `columns` and `data` (five people with a name, address, city and state), so everything you see is default behavior. For a table with more options set, see the [Advanced Example](/docs/examples/advanced).

<TryIt>

1. Click First Name and choose Sort ascending. The rows reorder.
2. Open search and type Nebraska. Two rows remain.
3. Clear the search. All five rows return.

</TryIt>
