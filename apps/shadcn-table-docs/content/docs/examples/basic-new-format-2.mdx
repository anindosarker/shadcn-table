Shadcn Table enables client-side sorting, filtering, search, pagination, column hiding, and more by default. These features can easily be disabled or customized further, but here is a showcase of their default behavior. Be sure to check out a more [Advanced Example](/docs/examples/advanced) to see how more features can be customized.

### Try it

<TryIt>

1. Click `First Name` and choose `Sort by First Name ascending`. The rows reorder.
2. Open search and type `Nebraska`. Two rows remain.
3. Clear the search. All five rows return.

</TryIt>
