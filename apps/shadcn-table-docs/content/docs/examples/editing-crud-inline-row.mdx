This example builds full CRUD (create, read, update, delete) with shadcn-table using the inline [`"row"`](/docs/guides/editing#row-editing-mode) editing mode: `editDisplayMode: 'row'` with `enableEditing` turns every cell of one row into inputs at once, and the row actions column shows save and cancel buttons while it is open. `onEditingRowSave` receives the new values and `onEditingRowCancel` drops them; new rows use `createDisplayMode: 'row'` and `onCreatingRowSave` in the same way.

The edit and delete buttons come from `renderRowActions`, and the create button from `renderTopToolbarCustomActions`. TanStack Query mutations update the table optimistically, so the edit shows at once while the request runs; hook in your own API calls to save the data to your backend.

Row editing suits records with a few related fields that should change together, such as a first and last name or a price and a currency, because the user saves them in one step. Check out the other editing modes below, and the [editing guide](/docs/guides/editing) for more information.
