Shadcn Table allows you to easily make the header and footer sticky while scrolling. See the [Sticky Header Feature Guide](/docs/guides/sticky-header) for more information.

## Try it

<TryIt>

1. Scroll inside the table. The header stays at the top and the footer at the bottom.
2. Scroll to the end. The footer row repeats the column names.

</TryIt>
