The `renderDetailPanel` option renders extra content below a row when you expand it. This table lists five people, and the panel shows a person's address, city, state and country. Rows 3 (Ervin) and 5 (Branson) have no address in the data, so the example renders no panel for them and their expand arrow is greyed out.

<TryIt>

1. Click the arrow on row 1. A panel opens.
2. Click the arrow on row 2. Row 1's panel closes.
3. Click the same arrow again. The panel closes.
4. Click the greyed arrow on row 3 or 5. Nothing happens.

</TryIt>
