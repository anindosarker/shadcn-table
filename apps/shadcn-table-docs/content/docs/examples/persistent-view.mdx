---
title: 'Persistent View Example'
description: 'An example of Shadcn Table that saves the view settings, the toolbar pins and the column layout to localStorage and restores them on reload.'
---

With `persistViewSettings: true`, Shadcn Table stores the view settings and the column visibility, order and pinning in localStorage and restores them on reload. Change a few settings or drag a column header, then reload the page. Learn more in the [View Settings Guide](/docs/guides/view-settings).
