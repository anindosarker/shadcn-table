Shadcn Table gives you a lot out of the box, but it's also easy to turn off any features that you do not need.

Every feature has an `enable...` table option that let's you turn it on or off.

For example, you can turn off sorting or hide the top or bottom toolbars if you want.

## Try it

<TryIt>

1. Click a header. Nothing happens: sorting and column menus are off.
2. Look above the table. There is no toolbar, only a caption that counts the 5 rows.

</TryIt>
