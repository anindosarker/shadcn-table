shadcn-table gives you a lot out of the box, but it is just as easy to turn off the features you do not need. Every feature has an `enable...` table option that turns it on or off: this example sets `enableSorting`, `enablePagination`, `enableColumnFilters`, `enableColumnActions` and `enableKeyboardShortcuts` to `false`, and renders only the table body with `ST_Table` inside `ST_TableProvider`, without the toolbars.

What is left is a plain table that still uses your shadcn/ui table components and theme. `renderCaption` adds a caption, and the `stTableProps`, `stTableHeadCellProps`, `stTableBodyRowProps` and `stTableBodyCellProps` options pass classes and attributes to the table elements, the same way you would style the shadcn/ui table directly.

Use this setup for small read-only lists, such as a summary in a card or a dialog, where controls would add noise. You keep the typed column definitions and can turn a feature back on later with one option.
